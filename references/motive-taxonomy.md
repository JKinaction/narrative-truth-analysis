# 人性偏移机制与叙述目的

两部分：
- **A. 人性层**：语言偏差的系统性来源（人几乎不会凭空捏造整件事，更常见的是在真实事件上做系统性偏移）。
- **B. 目的层**：讲者希望听者做什么，以及如何识别。

---

# A. 人性层：偏移机制表

不要用"是否说谎"的二元框架。逐项检查文本中是否出现该机制。

| 机制 | 定义 | 文本表现 | 检测方法 |
|---|---|---|---|
| **自利性偏差** | 保护自身利益的系统性倾向 | 我方 = "沟通不畅""时机不对"；对方 = "故意拖延""态度恶劣" | 把所有归因动词列出来，看是主动还是被动、是针对谁 |
| **自我服务偏差** | 成功归功于自己，失败归因于情境 | "我推动的""事出有因" | 找出叙述中所有成果与挫折的归因，看分配是否对称 |
| **基本归因错误** | 把对方行为归为性格，把自己的行为归为情境 | 对方 = "他就是这德行"；自己 = "我不得不这样" | 检查"因为他人品质"与"因为客观条件"这两类解释的出现频率 |
| **情绪回填** | 当下情绪被投射为过去事件带出的感受 | "当时就觉得不对劲""那一刻我就明白了" | 问"当时最强烈的感觉是什么"，若与现在的情绪高度一致且过于清晰，反而存疑 |
| **自我叙事连贯性** | 讲述者需要故事讲得通，把碎料补成因果 | 缺失环节被自动补上 | 标出每一个"所以"前后是否缺了行动步骤 |
| **选择性记忆** | 记得对自己有利的部分 | 顺序颠倒、细节被重排 | 追问"当时你先做的还是先说的" |
| **确认偏误** | 只收集支持既有立场的信息 | 大量引用支持性证据，回避反例 | 问"有没有任何一件事能支持对方" |
| **旁观者偏差** | 容易高估自己在事件中的重要性 | 事件被大量叙述成围绕自己展开 | 问在场的其他人当时在做什么 |

**共同特征：这些机制全部作用在"归因"和"情绪"上，很少作用在"发生了什么"上。**

所以 —— **事实骨架通常是真的，被污染的是责任归属和情绪强度。** 这也是为什么默认假设应该是 H2 而不是 H3。

---

# A2. 高性价比检验：反向叙述

让同一个人**从对方视角**重述同一事件。

- **顺畅、具体、不带抵抗地复述对方视角** → 事实骨架是硬的，他不是在辩护。
- **复述时不断加"其实他可能也是……""换作我也……"这类补丁** → 他在为自己这一侧辩护，事实骨架可能没问题，但归因被垄断。

这是投入产出比最高的一项检验，因为它不需要外部证据，只需要一个提问。

---

# B. 目的层：六类叙述目的

目的 ≠ 可信度。带目的的叙述完全可能是真的 —— 人都会带目的地讲真话。要做的是把"事实层真伪"和"意图层真伪"分开写。

## B1. 目的类型表

| 目的类型 | 语言信号 | 讲者的实际收益 | 验证方向 |
|---|---|---|---|
| **免责自保** | 大量被动句与无名主语；把结果归给流程或"上面"；时间线模糊；用"沟通""对接""机制"等抽象名词代替具体动作 | 避免被追责，保住位置或补偿 | 查流程文件里的签字人与时间戳，看责任是否真的不在他 |
| **争夺叙事权** | 叙述完整、结论先行、结尾升华；主动定义对方行为的性质（"他就是在推诿"）；用词有明显的立场倾向 | 抢先定义"这事到底是谁的问题"，让后续讨论在自己的框架里进行 | 找更早的第三方说法，看这个定义是谁先提出的 |
| **情绪勒索** | 事件严重度与描述强度不匹配；细节铺陈多、事实主张少；反复出现"最""从来""再也" | 换取同情、支持、补偿或舆论压力 | 把情绪与事实分开问：单独只问可核实的事实，看强度是否塌陷 |
| **谈判筹码** | 先讲最有利于自己的部分；结尾留一个明显的开口；细节密度到某个点突然停下 | 为即将到来的谈判定锚，让对方在预设范围内还价 | 看那个开口是否正好朝着他想要的让步方向 |
| **造势传播** | 面向不特定多数；强调"大家都……""很多人……"；缺少可查证的私事细节；语言有传播性 | 让版本扩散、占住舆论位置、抢定义权 | 找最早发布渠道与最早持有者，判断是自造还是被喂 |
| **留证备案** | 极度平实、时间精确、不作评价、主动交代对自己不利的事实、有意省略情绪词 | 给自己留一份将来可复用的记录 | 与同期其他文件、聊天记录比对，用词风格是否一致 |

## B2. 最硬的一问：谁受益（cui bono）

对每一种可能的目的，问一句：**这段描述被听者接受之后，谁得到好处？**

- 答案是"讲的人" → 描述的偏差方向就可预期了。
- 讲的人自曝了对己不利的事实 → 可信度上升（真实回忆者常这么做）。
- 讲的人恰好在关键处沉默 → 那段沉默的位置就是利益所在。

## B3. 时机的功能

同样的内容，时机不同意义完全不同：

| 时机 | 典型含义 |
|---|---|
| 事情刚发生 | 情绪未加工，细节最丰富，也最不完整 |
| 追责/仲裁前 | 立场化最强，通常在定锚 |
| 追责/仲裁后 | 若叙述与此前版本不同，看是修正还是加码 |
| 与己方不利消息同时出现 | 可能是抢时间、也可能是真的想到才说 —— 必须比对更早版本 |
| 长期沉寂后突然讲述 | 通常有新的目的（新的冲突、新的诉求、新的听众） |

**检验**：问"你之前跟 X 说过这件事吗？什么时候？说了什么？" 拿更早版本做比对，是判断加工过程最直接的证据。

# C. 目的判断的输出要求

分析时不要停在"他大概是在推卸责任"，要给出：

1. **最可能的 1–2 种目的**（可并列），及各自依据。
2. **每种目的对应的验证方向**（见上表最右列）。
3. **该目的是否与事实层真伪相关** —— 多数情况下**不相关**。目的是"免责"和"事实造假"是两回事。
4. **目的与时机的匹配度** —— 如果目的与时机不匹配（追责后突然讲一件对自己不利的旧事），要么是真心反思，要么是叙事水平异常高，两种都要在报告里点出。
