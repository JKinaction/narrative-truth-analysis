# 话里有话：语用层拆解手册

> 处理"表面意思之外还有意思"这一类问题。
> 与 `signal-catalog.md` 的分工：那份读**文本结构**，这份读**言语行为**。

---

## 先划清一条线

**能做的**：标注"这句话在做什么动作"、"它回避了什么"、"它预设了什么"。
这些都有语言形式上的依据，可以指出来给人看。

**不能做的**：判断"他心里到底怎么想"、"他是不是在针对我"。
这需要读心，任何方法都做不到，声称能做到的都是骗人。

所以输出永远写成"**看起来在拒绝**"而不是"**他在拒绝**"。
区别不是措辞客气，是认识论上的诚实：**你看到的是语言动作，不是动机。**

---

## 一、核心框架：四准则违反检测

源自 Grice 的合作原则。人在正常交流时默认遵守四条准则，**一旦违反，就产生了言外之意**。

这是"话里有话"最硬的理论骨架——不是靠感觉，是靠"他违反了哪条"。

| 准则 | 正常表现 | 违反时的信号 | 常见话术 |
|---|---|---|---|
| **数量** | 该说的都说了 | **说太少**（省略关键）/ **说太多**（淹没重点） | "这事比较复杂" / 长篇大论绕开一句关键 |
| **质量** | 说确定的 | 话说得过满、举证不足 | "绝对没问题" / "我保证" |
| **关系** | 答所问 | **答非所问**（回避） | 问"能不能"答"我们很重视" |
| **方式** | 说清楚 | **故意含糊** | "那个事""你懂的""看情况" |

### 用法

拿到一段话，先问：

1. 它**说得比该说的少**吗？少的那部分是什么？
2. 它**答的是我问的那个问题**吗？如果不是，答了什么？
3. 它有没有**故意说不清**的地方？哪个词最含糊？
4. 它有没有**说得太满**？满在哪里？

四个问题里命中的那个，就是"话"藏着"话"的位置。

## 二、言语行为：这句话在做什么

一句话同时在干三件事。日常交流里，我们只注意第一层。

| 层 | 内容 | 例 |
|---|---|---|
| **言内** | 字面说了什么 | "这个方案我们内部再讨论一下" |
| **言外** | 在做什么动作 | **拒绝**（而且是不给理由的拒绝） |
| **言后** | 想让你产生什么反应 | 让你停下来，且不要追问 |

**拆解的关键是把"言外"单独写出来。**

日常对话里，人很少直接做"拒绝""施压""试探"这些动作，而是用一句陈述句包装。
包装的作用是：**动作做完了，但可以不承认做过。**

常见言外动作清单：

| 言外动作 | 常见包装 | 识别点 |
|---|---|---|
| **拒绝** | "再研究一下""走流程""看情况" | 没有时间点、没有下一步、没有责任人 |
| **拖延** | "最近比较忙""等这段时间过去" | 只给状态，不给日期 |
| **试探** | "随便问问""我听说……" | 用一个假设句式问真问题 |
| **免责** | "我早就提醒过""当时我就说" | 时间状语前置到最前 |
| **施压** | "你自己考虑""我不勉强" | 把选择权推给你，但代价已经摆好 |
| **转移** | "这个要看上面""不是我定的" | 主语换成一个不在场的人 |
| **降温** | "也不是什么大事""别往心里去" | 先否定事件的重要性 |
| **抬高门槛** | "你要是能……我们就……" | 条件在前，承诺在后且模糊 |

## 三、预设提取：一句话里夹带的私货

**预设**是一句话成立所默认的前提。它不说出来，但要求你接受。

这是"话里有话"最隐蔽、也最容易击穿的形态——因为对方可以否认说过，但否认不了预设。

### 触发词表

| 触发结构 | 预设 |
|---|---|
| "你为什么还没……" | 你**应该**已经做了 |
| "这个**还是**有问题" | **之前就有**问题 |
| "你**又**迟到了" | 你**多次**迟到 |
| "把**那个**事处理一下" | 我们**都清楚**是哪个事 |
| "**连**他都同意了" | 他本来是**最不可能**同意的 |
| "你**居然**不知道？" | 你**理应**知道 |
| "**既然**你都这么说了" | 你已经做了一个**承诺** |

### 用法

把一句话里的预设摊开，问：**这个前提成立吗？**

如果不成立，整句话就不成立——但对方的语气会让你觉得是自己理亏。

**这是最该反击的地方，也是最容易漏掉的地方。**
因为人会自动接受预设，注意力都放在后面的问题上。

## 四、语用标尺：弱词就是弱评价

同一个意思有一串强度不同的词。**选了弱的那个，就是在说弱的那件事。**

| 说的话 | 实际强度 | 翻译 |
|---|---|---|
| "非常好" | 100 | 真的好 |
| "还不错" | 60 | 及格，但没打动我 |
| "挺有想法的" | 40 | 不实用 |
| "很有特色" | 30 | 我不喜欢但不好直说 |
| "我们会研究一下" | 10 | 不会有下文 |
| "有机会再合作" | 5 | 没有下次 |
| "我考虑考虑" | 3 | 不打算 |

**规律**：越正式的场合，人越倾向选弱词。所以看到弱词，不要按字面理解。

**动作**：把对方用的词，和他可能用的最强词做对比。**差距就是他的真实态度。**

## 五、元话语标记：免责声明的位置

有些词本身不承载信息，只在为后面的话**铺路**。

| 标记 | 后面是什么 |
|---|---|
| "说实话" | 平时不敢说的话 |
| "不是我说你" | 批评 |
| "我就直说了" | 不客气的话 |
| "按理说" | 准备破例 |
| "我个人认为" | 要说不方便代表立场的话 |
| "先说明一下" | 要开始推责任 |
| "有句话不知当讲不当讲" | 不当讲的那句 |

**用法**：这些标记出现的位置，往后数一到两句，就是真正想说的内容。
标记本身可以忽略，它的作用是**降低说出口的心理成本**。

## 六、否定式缓冲：A 是顾虑，B 才是真意

结构："不是 A，而是 B" / "我不是嫌 A，只是 B"

**A 通常是对方预料到你会有的反应，B 才是真实障碍。**

| 原话 | 表面 | 实际 |
|---|---|---|
| "不是嫌贵，是觉得不值" | 价格不是问题 | 就是价格问题，只是要一个理由 |
| "不是不信任你，是流程要求" | 信任没问题 | 不信任，但用流程挡 |
| "我不是针对你" | 对你没意见 | 就是针对你 |
| "不是不想帮，是实在没办法" | 愿意帮 | 不想帮 |

**动作**：把 A 划掉，只看 B。B 是真正的信息。

---

## 七、回避映射：问 A 答 B

这是最容易操作的一招，也最容易验证。

**做法**：把"我问的"和"他答的"并排列出来。

| 我问的 | 他答的 | 中间缺的 |
|---|---|---|
| 什么时候能给答复 | 我们很重视这个事 | **日期** |
| 这个多少钱 | 我们性价比很高 | **数字** |
| 是谁决定的 | 这是集体决策 | **人名** |
| 能不能改 | 需求已经定了 | **"能不能"这个问句** |

**被跳过的那个词，就是禁区。**

而且它有个好处：**不需要判断对方意图**，只需要做形式比对。属于"看得见"的证据。

---

## 八、人称滑动：责任怎么被摊薄

| 人称 | 效果 |
|---|---|
| "我" | 承担 |
| "我们" | 分摊（但谁都不具体） |
| "上面""公司""领导" | 完全转移，且无法追责 |
| "有人""大家" | 制造多数，压制异议 |
| "你" | 反转为对方的责任 |

**一段话里人称怎么滑，责任就怎么被摊走。**

特别注意："上面要求"——问一句"哪位"，多数时候对方答不出来。

## 输出模板

拆一句话，按这个格式给：

```
原话：___

字面：___（他具体说了什么）

言外动作：___（拒绝 / 拖延 / 试探 / 施压 / 免责 / 转移 / 降温）

回避了什么：___（我问的 vs 他答的，缺的那块）

预设了什么：___（这句话默认成立、但没证明的前提）

可以怎么接：___（一句具体的话，不是"建议你沟通"）
```

### 关键在最后一行

不给"你可以试着跟他沟通"这种废话。给**能直接说出口的那一句**。

原则：把模糊的地方钉成具体的。
- 模糊的时间 → 要日期
- 模糊的主体 → 要人名
- 模糊的条件 → 要书面
- 模糊的评价 → 要标准

例：
- 他要"再讨论" → "好，那定个时间，下周几？谁参加？"
- 他说"上面要求" → "哪位提的？我去跟他确认一下细节。"
- 他说"尽量" → "尽量到什么程度？如果做不到，最晚什么时候告诉我？"

## 三条限制

1. **语用推断依赖语境。** 同一句话在上下级、亲密关系、陌生人之间，言外动作完全不同。
   缺语境时必须说明"若这是平级沟通，则……；若这是上级对下级，则……"。

2. **不能靠语气和表情。** 纯文本场景（微信、邮件）可以做；
   但对方如果打了电话或当面说了同样的话，语气可能推翻全部判断。

3. **不要把所有话都当"有话"。** 大多数日常交流是真诚的、字面的。
   只在**有利益冲突、有信息不对称、有话说不出口**的场合，才值得拆。
   滥用这套方法会把人变成疑神疑鬼——这也是一种失真。
