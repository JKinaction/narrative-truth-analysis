# 验证方法手册

## 核心原则：找区分性检验，不是找支持性证据

**错误做法**：找一个能证明 H1 的证据。
**正确做法**：找一个 **H1 和 H2 会给出不同结果** 的动作。

例：
- 错误 → "找证据证明他确实被怠慢了"
- 正确 → "他说当时在会议室，对方当着所有人拒绝。这件事有会议记录吗？"（若真，走向 H1；若编，会出现时间/参与人细节对不上）

---

## 一、区分性检验清单

按"能否分开竞争假设"排序。

### 1. 时间锚点检验

**做什么**：从叙述中提取所有时间锚点（具体日期、"那天""上周三""大概三四点"），去比对客观记录：打卡、邮件时间戳、订单、监控、聊天记录、报销单、通话记录。

**能区分**：H1（锚点对齐）/ H2（骨架真但时间被压缩或模糊）/ H3（锚点漂移或根本不存在）

**注意**：真实叙述的锚点会有偏差，容差按场景定（"三个月前"和"上季度"是同一件事，不算矛盾）。只抓**硬冲突**：叙述说"当天晚上就发了消息"，记录显示消息是三天后发的。

---

### 2. 过程复现检验

**做什么**：问只有在场者才能答、且不涉及是非的问题。

**范例**：
- "那天会议室的椅子是排成一排还是围成圈？"
- "当时空调坏着吗？"
- "你是几点到的，比他早还是晚？"
- "你当时手里拿着什么？"

**为什么有效**：这类问题答不出来 = 不在场；答得出来但和叙述矛盾 = 关键证据；答出来且吻合 = 骨架可信（**注意**：只能证明在场，不能证明叙述内容为真 —— 一个在场的人也可能撒谎）。

---

### 3. 细节诱导检验（可用于访谈，也可用作文本比对）

**做什么**：不直接问，而是抛出一个**错误细节**，看是被纠正还是被吸收。

- "我记得那天是王总在场吧？"（实际不是）
- 真人 → 明确纠正："不是王总，是老陈。"
- 有人在编 → 通常会吸收，或含糊地顺着说下去。

**文本版替代**：拿叙述者早期版本和其他人的版本做比对，看**新细节是被吸收还是被纠正**。越晚的版本吸收越多，说明加工成分越高。

**风险提示**：诱导提问会破坏信任，只能在已有关系或非正式场合使用，不可用于正式取证。

---

### 4. 反向叙述检验

**做什么**：让叙述者从对方视角复述同一事件。

**解读**：
- 顺畅具体、不抵抗 → 事实骨架硬
- 不断加"其实他可能也是……"补丁 → 在辩护，事实骨架或真，但归因被垄断

---

### 5. 第三方独立检验

**做什么**：找不在场或场边的人。

**关键**：问**能区分假设**的问题，不要问"你觉得他说得对吗"（会得到迎合或抹黑）。要问具体的、双方都可能答错的事实。

**信度排序**：无利害关系的在场者 > 有利害关系但陈述与自身利益矛盾的第三方 > 当事双方 > 转述链条中的人。

**红旗**：多个"独立"证人的说法高度一致且用词相同 —— 可能是统一过口径，不是独立印证。

---

### 6. 事前预测检验（最强，但需要时间）

**做什么**：让叙述者就事件后续做出**具体、可验证的预测**，然后等结果。

- "他下周会主动找我谈这件事。" → 记下来，到期核对。
- "这个价格不会再涨了。" → 记录，到期核对。

**为什么强**：编造者可以编过去，但很难持续地编未来 —— 未来一旦落空，造假动机就暴露了。

**注意**：也要记录他预测**自己**的行为，"我会离职"，看是否发生。

---

### 7. 稳定基线检验

**做什么**：找叙述者对**不同听众、在不同时点**讲同一件事的版本。

**解读**：
- 版本间说法基本一致 → 可信度上升
- 每次都**新增**受害者细节、**新增**严重性 → 随听众调整，目的层在起作用
- 每次都**减少**细节、越来越谨慎 → 真的在反思或收敛
- 早期版本最详细、后期版本最概括 → 可能是真的在收敛，也可能是发现原版有漏洞而修补，需要分辨

**怎么拿**：问"你之前跟谁说过这件事？还跟谁讲过？" 拿到版本差异是判断加工过程最直接的证据。

---

### 8. 沉默与缺席检验

**做什么**：列出事件中"本该在场或本该知情"的所有角色，看谁被省略了。

**解读**：
- 被系统性省略的第三方 = 利益所在
- 叙述中唯一被提及的证人，往往是叙述者的盟友或已被说服的人
- 叙述者从不提自己在事件中的主动行为（只写"被""遭到""结果"）→ 免责倾向

---

### 9. 量化信号检验

运行 `scripts/analyze_narrative.py`，把以下指标作为辅助信号（**不作为结论依据**）：

| 指标 | 意义 |
|---|---|
| 被动句比例 | 责任稀释程度的粗略度量 |
| 模糊限定词密度 | 关键处的确定性缺失 |
| 情绪词位置分布 | 情绪峰值是否落在戏剧点上 |
| 细节碎屑计数 | 特异性强度 |
| 句长方差 | 真实回忆句长参差；模板化叙述整齐 |
| 时间锚点数 | 时间线是否有洞 |
| 主张与支撑配比 | 主张多、支撑少 = 情绪勒索倾向 |

## 二、验证成本与优先级

按"成本 / 区分度"排：

| 优先级 | 动作 | 成本 | 区分度 |
|---|---|---|---|
| 1 | 已有客观记录的时间锚点比对 | 极低 | 高 |
| 2 | 早期版本比对 / 稳定基线 | 低 | 高 |
| 3 | 反向叙述 | 低 | 中高 |
| 4 | 过程复现式提问 | 低 | 中高 |
| 5 | 第三方独立询问 | 中 | 高 |
| 6 | 细节诱导 | 中 | 高（有风险） |
| 7 | 事前预测记录 | 零（即时） | 高（延迟兑现） |
| 8 | 正式取证（笔录、录音、鉴定） | 高 | 高 |

**原则**：先做成本最低、区分度最高的 1–3 项，再决定要不要付出高成本。

## 三、提问脚本

### 开场：建立基线（不问是非）

- "从头讲一遍这件事，不用管我想听什么，想到哪说到哪。"
  → 观察：先讲什么、后讲什么、哪里含糊、哪里开始补充细节。

### 推进：拉开差异（区分假设）

- "这件事你跟别人说过吗？什么时候，说给谁？"
  → 拿早期版本。
- "如果从对方的角度讲，这件事是什么样的？"
  → 反向叙述。
- "当时还有谁在场？他们各自在做什么？"
  → 过程复现 + 缺席检验。
- "你怎么知道这一点的？是当时看到的还是后来听说的？"
  → 区分亲历与转述，直接暴露信息链条长度。

### 收口：找可证伪点

- "有没有任何一件事能说明对方是有意这么做的？"
  → 逼出真实判断，还是只给情绪。
- "如果我说的和你说的不一样，你觉得哪里不一样？为什么？"
  → 制造轻度分歧，看他是澄清还是退让。
- "关于这件事，还有什么是你现在没说但觉得该说的？"
  → 邀请遗漏。注意：如果回答是流畅的，说明是被准备过的。

### 不要问的

- "你是不是在撒谎？" —— 关闭对话，且暗示结论。
- "你觉得他是不是故意的？" —— 只要立场不要事实。
- 诱导性预设（"你也觉得他很过分吧？"）—— 得到的是迎合。

## 四、报告验证清单

输出分析报告前自检：

- [ ] 每个事实主张都标了证据来源（亲历 / 听说 / 推测）
- [ ] 每个事实主张都标了可证伪性
- [ ] 至少列了 3 个竞争假设，且包含 H2
- [ ] 每条验证建议都说明它**能区分哪两个假设**
- [ ] 明确写了"什么能推翻当前判断"
- [ ] 事实层与意图层的结论分开写
- [ ] 结论用概率表述，未下判决
- [ ] 未对任何一方的人格或动机作道德判断
