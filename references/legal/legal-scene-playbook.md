# 法律场景专项：当事人陈述的拆解方法

法律场景是这套方法论的**高价值应用场景**，因为它天然带着别处没有的东西：**真值是现成的**。裁判文书里同时写着当事人陈述和法院查明，两者一对照，偏移立刻暴露。

本文件的核心价值不是案例本身，而是**六组"陈述 vs 查明"的实际差异模式**——它们把抽象的偏移机制落成了可复用的检查项。

配套数据见 `case-comparison.md`（六案逐句对照）。

---

## 一、先做一次"文体降级"判定（最重要的一步）

**法律文书里的"当事人陈述"通常不是当事人原话。**

真实分布：

| 文书位置 | 实际作者 | 语言特征 |
|---|---|---|
| 诉状"事实与理由" | **律师**（当事人可能没看过全文） | 高度压缩、无碎屑、句长整齐 |
| 答辩状 | 律师 | 同上，但带防御性反驳结构 |
| 询问笔录 / 庭审陈述 | 当事人（可能是复述） | 有口语、有停顿、有自我修正 |
| 情况说明 / 自述 | 当事人 | 最接近原始叙述 |
| 证据（借条、合同、录音） | 书证 | 不含叙述，另有真伪规则 |

**实测数据（用 `scripts/analyze_narrative.py` 跑六份诉状）：**

| 案例 | 细节碎屑密度 | 句长变异系数 |
|---|---|---|
| 王某诉张某（借贷） | 0.0/千字 | 0.42 |
| 章XX诉铁通（健康权） | 0.0/千字 | 0.30 |
| 甲公司诉大舅子（虚假诉讼） | 0.0/千字 | **0.05** |
| 吕某诉杨某（虚假诉讼） | 0.0/千字 | 0.59 |
| 西某软件诉沃某模具（律所诉状） | 0.0/千字 | 0.42 |

**重要修正（2026-11-08 补入婚姻遗产案例后）**：上一版把"碎屑密度为 0"归因于律师改写，
这个解释**部分错误**。孙丰杰案是当事人**自己写**的起诉内容，碎屑密度同样是 0，
但时间锚点 6 处、精确数字 13 处、句长变异 0.46，与律师改写的 M1（变异 0.16、时间锚点 3）明显不同。

→ **碎屑密度不是"律师改写"的产物，而是"起诉状"这一体裁的共同特征** —— 起诉状本就是书面整理的，
  当事人自己写也会被整理成书面语。

→ 修正后判据：**能区分"自写 vs 他人加工"的是时间锚点密度 + 精确数字密度，不是碎屑。**
  自写陈述会保留更多具体时间点和金额，因为他知道这些细节且急于证明；
  他人加工会保留结论、抹掉具体。

**修正后的信号优先级（法律场景）**：

| 有效信号 | 无效信号 |
|---|---|
| 版本稳定性（同一笔钱前后说法是否一致） | 碎屑密度 |
| 选择性提交（是否只交对自己有利的证据） | 句长整齐度 |
| 时间邻接（行为是否紧贴程序节点） | 情绪词多少 |
| 关系/权属披露完整度 | 抽象名词密度 |
| 诉求构造偏移（主张是否超出事实能支撑的范围） | 被动句比例 |
| "说不清去向"（能否解释资金/财产流向） | |

**推论（重要）**：
1. **不要用诉状判断当事人是否诚实**。五个案子里有真陈述也有假陈述，碎屑密度全是 0。
2. 要判断诚实，必须拿到当事人本人的原始陈述：询问笔录、庭审陈述、情况说明、**书面自述**。
   注意"书面自述"也已被起诉状体裁格式化，只能靠时间锚点密度、精确数字密度、版本稳定性判断。
3. 第三方版本（法院查明、对方陈述、鉴定意见）不受文体降级影响，是更可靠的比较基准。

## 二、六组案例揭示的六种偏移模式

这六种是从真实裁判文书的"陈述 vs 查明"对照里提炼的，可直接当检查清单用。

### 模式 1：记忆的合理化压缩（王某案）

**陈述**："2020年12月份，张某因需资金向王某借款35000元，2020年12月10日书写借条一张。"
**查明**：12月7日借5000元，12月10日借30000元并出具借条（借条载明35000）。

**偏移**：把两笔合并成一笔，日期取借条出具日。
**根因**：借条上只写35000，叙述者据此反推"我借了35000"，**文书反噬记忆**。
**识别信号**：差异可用"当时手上有什么单据"完全解释 → 是加工痕迹，不是虚构。
**真伪判定**：真实（高度压缩）。

> **可推广**：当事人有书面凭证时，记忆会被凭证同化。看到"陈述与单据不一致但总额对得上"，先查是不是这个机制。

### 模式 2：语感失真 + 关键限定词隐藏来源（章XX案）

**陈述**："王XX急忙刹车，导致车辆翻倒，将原告从车上甩到地上"
**查明**：为躲避线缆紧急刹车，翻车；**王XX承担70%主要责任**

**偏移**："甩到地上"暗示被抛飞，弱化了王XX自身的操作过错。
**另一处**："**经了解**，该线缆为第一被告员工张晓龙施工设置" —— 限定词"经了解"揭示这是外部得知，非亲历。

**识别信号**：诉状里凡是"经了解""据称""据了解""听说"开头的关键事实，**都是当事人无法直接观察的部分**，也是最需要外部核实的地方。

**真伪判定**：事实骨架真，一处语感失真。

### 模式 3：时序倒置（甲公司案）—— 最硬的一类

**陈述**："被告大舅子因购买车辆向妹夫杨某借款"
**查明**：2017年4月7日购车，**10月22日**才转账，且摘要为"缴税款""代缴税款"。

**偏移**：借"购车"的钱，晚半年才到账；用途与摘要不符。
**法院原话**："原告的陈述自相矛盾，且明显有悖生活常理。"

**识别信号**：**把陈述里所有"事由"和"时点"拉成时间轴，看因果顺序是否成立**。这一项能独立击穿谎言，且不需要任何证人。

**真伪判定**：虚假诉讼。

### 模式 4：精确度异常（甲公司案）

**陈述**："共71430.69元"
**法院查明**：同一金额，银行转账。

**判决书自己点出**："**金额精确至角分**，证明双方之间另有交易往来。"

**为什么这是信号**：正常的大额往来会抹掉零头（银行转账通常只到角，且实务中习惯取整）。精确到分，说明这个数字是**为了匹配某个既有数额而倒推**出来的。

> **可推广**：金额精确度是判断"凑数"的高性价比指标。整千整万 → 真实现金/整额往来；精确到分 → 后台构造。

### 模式 5：形式无懈可击，矛盾只在"资金来源"这一层（吕某案）

**陈述**：10张借条、4个日期、金额各异、逐笔对应转账、"筹集自有资金和向朋友借款"
**查明**：1240万元实为农商行当日发放给**吕某自己控制的公司的贷款**；10张借条是"对着银行流水伪造的"。

**这是本组最重要的发现**：形式越完整，越要往上游查。吕某案里每一项表面证据都能自洽，**唯一击穿它的是"钱从哪来"** —— 而这需要调取资金来源，不是核对借条。

**附带的两个非语言红旗**：
- **"杨某对上述借款事实全部认可"** —— 表面无争议。虚假诉讼中"双方高度一致"本身就是信号，因为串谋者不会配合对质。
- **时间抢先一天**：对方 3月17日申请诉中保全，吕某 3月16日抢先申请诉前保全。

### 模式 6：关系披露程度 + 群体特征（杨某某船员案）

**主张**：提交《船员劳务合同》和欠条，请求支付26.4万元劳务报酬并确认船舶优先权。
**未披露**：杨某某与方某某是**夫妻**；5名船员中另4名是近亲属；欠条是**船舶被扣押后**才出具的。
**法院认定**："夫妻二人对外为一个经营主体，二人之间不能成为雇主与雇员关系。"

**最高法院自己公布的识别依据**：
> "船舶经司法拍卖后，被执行人为从拍卖款中非法受偿，与船员串通伪造、虚增债务的现象时有发生。"

**识别信号（可直接迁移）**：
- 主张人与对方是**近亲属**，而陈述里只说"我的雇主" —— 关系披露程度本身就是证据
- 关键书证（欠条）**出具于程序节点之后**（扣押后、保全后）—— 补充书证的时间点
- 同一主张的**群体构成异常**（5人里4人是亲戚）

## 三、唯一一组"双版本直接对撞"：熊某某工伤认定

红安案（红政复决〔2025〕4号）是本组唯一双方陈述正面冲突的样本，胜负手极其清晰：

| 主张方 | 提交物 | 复议机关评价 |
|---|---|---|
| 职工熊某某 | "2022年8月份—湖北天诚B组—考勤表"，显示事故当日为工作日 | "**其拍摄考勤表有明确的时间与地点**，另外其也无法伪造他人的考勤信息" |
| 单位天诚公司 | 同名考勤表，显示事故当日未安排上班 | 未提交原件，7月24日举证通知书后未举证 |

**关键洞察：胜负手不在表的内容，在"这张表怎么来的"。**

- 职工的表带**拍摄的时间与地点元数据** —— 不可逆的生成痕迹
- 单位的表是打印件，职工无从伪造他人考勤信息
- 谁掌握了生成痕迹，谁的陈述就更可信

> **可推广的判据**：两份材料内容冲突时，先问"哪一份带有不可逆的生成痕迹"（元数据、原始载体、有第三方签章的原件、形成于特定时点的痕迹）。这可以脱离内容做真伪判断。
>
> 这也呼应 `verification-playbook.md` 里的"时间锚点检验"—— 只是这里锚点变成了**元数据**。

## 四、法律场景的验证动作（按性价比排序）

法律场景的优势是"可查证锚点"极多，不必依赖语言直觉。

| 优先级 | 动作 | 能击穿什么 |
|---|---|---|
| 1 | **调取原始书证**（借条原件、转账凭证、回单） | 模式1（压缩）、模式4（精确度） |
| 2 | **拉时间轴**：把陈述里的事由与时点排序 | 模式3（时序倒置） |
| 3 | **调取银行流水与摘要** | 模式3、模式4、模式5（资金来源） |
| 4 | **查资金来源**：钱到底从哪来、谁是实际用款人 | 模式5（最难击穿的一类） |
| 5 | **查书证形成时点**是否在程序节点之后 | 模式6 |
| 6 | **查主张人与对方的亲属关系 + 群体构成** | 模式6 |
| 7 | **看双方是否"毫无争议"** | 模式5 |
| 8 | **看时间抢先/跟随关系**（谁比谁早一天） | 模式5 |
| 9 | **调取元数据**：原件的拍摄时间、地点、生成设备 | 熊某某案 |

## 五、法律场景的常见目的类型（对照 `motive-taxonomy.md`）

| 目的 | 典型表现 | 案例 |
|---|---|---|
| **免责自保** | 诉状中不披露对自己不利的关系（"妹夫"不提、"夫妻"不提） | 甲公司案、杨某某案 |
| **争夺叙事权** | 抢先一天申请保全；把3840万拆成10件规避审查 | 吕某案 |
| **择时施压** | 专挑对方财产被没收前起诉，主张优先受偿 | 甲公司案 |
| **转嫁责任** | "经了解"式限定词把不可知部分推给不知情的人 | 章XX案 |
| **真实维权** | 诉求与证据方向一致，主动承认对自己不利的事实（"经了解"来源不明） | 章XX案、王某案 |

**注意最后一行**：章XX案和王某案都是**真实维权**，而甲公司案、吕某案、杨某某案是**串谋或虚构**。两组在语言层指标上无法区分——只能靠时序、资金来源、关系披露这类**外部核验**。

> **这是法律场景给这套方法论上的一课**：语言层能筛出"需要细查的"，但筛不出"假的"。**真伪的最终判定权在外部证据，而不在文本。**

## 六、给使用者的操作建议

1. **先定位文体层级**。拿到的是诉状还是当事人原始陈述？决定方法选哪一层。
2. **优先做时间轴**（模式3）。成本最低，且能独立击穿谎言。
3. **优先查资金来源**（模式5）。这是连形式完整的证据都挡不住的一击。
4. **关系披露检查**（模式6）。翻遍诉状找"我的雇主""对方"，看有没有本该出现的身份关系被抹掉。
5. **不要用诉状判断诚实度**。用语言层指标评价一份律师写的诉状，等于用错尺子量东西。
6. **以法院查明、鉴定意见、书证原文作为"真值侧"基准**做对照，而不是拿另一个当事人的说法当基准。

# B. 婚姻 · 遗产继承专项

针对家事案件的偏移模式、验证动作与特殊判据。详细逐句对照见 `case-comparison-family.md`。

## B1. 家事案件独有的五种偏移模式

### 模式 1：版本漂移（指导案例66号）—— 本组最强信号

同一笔 19.5 万元，当事人的解释前后变了：
- 一审：提交账户（尾号4179）自 2014年1月26日起的交易明细，显示至 2014年12月21日余额 **262.37元**
- 二审法院调取完整流水（自2012年11月26日开户后）发现：2013年4月30日通过ATM转账及卡取转出 **195000元**
- 解释：**"始称该款用于家庭开销，后又称用于偿还其外甥女的借款"**

法院认定："雷某某始称该款用于家庭开销，后又称用于偿还外债，**前后陈述明显矛盾**…"

> **判据**：不需要判断哪个解释是真的。**"存在两个解释"这件事本身就是结论。**
> 这完全绕开了"谁更可信"的争论，直接指向"当事人没有稳定的故事"。

**附带一个重要技术点**：当事人主动提交的交易明细显示余额几乎为零，单看像在证明"我没钱"。
二审调完整流水才发现是转走了19.5万。
→ **自证清白的证据本身可能是精心选择的切片**。银行流水可以只打印一段。

### 模式 2：选择性提交 / 隐瞒同源证据（海淀隐匿遗嘱案）

两份公证书**都是原告张女士去领的**。她提交了对自己有利的那一份（留给自己的），
藏了另一份（王先生放弃继承前妻份额的公证）。

法院认定："案涉两份公证遗嘱**均为原告领取**，在向法院提交了涉案房屋由其继承的公证遗嘱原件的同时，
未提交王先生放弃继承遗嘱公证书…**可以证明原告存在隐匿遗嘱的事实**。"

判决：应得50%，实得45%。

> **判据**：
> 1. **谁持有证据**（都是她领的）
> 2. **谁有披露义务**
> 3. **是否只提交了对自己有利的部分**
>
> **陈述不是编的，是漏的。漏掉的比说出来的更致命。**
> 注意张女士说的每句话都是真的 —— 她的陈述真实但不完整，而法律关心的是完整性。

### 模式 3：时间邻接暴露（汤阴转移存款案）

原告起诉是 3 月。两张存单销户是 **2022年3月1日、3月2日**。

法院认定依据："该两张存单已分别于2022年3月1日、3月2日销户，原告提前支取未到期存单，
**利息实际未能支取**…原告对提前支取未到期存单**不能作出合理解释**，
鉴于原告存在隐藏、转移夫妻共同财产行为，应当少分该部分财产。"

> **判据**：
> 1. **行为发生的时间点是否紧贴程序节点**（起诉前三天销户）
> 2. **是否存在可证伪的具体动作**（提前支取未到期存单 → 利息实际未能支取）
> 3. **当事人能否解释资金去向**
>
> **"行为发生在哪个时间点"比"当事人怎么解释那个时间点"更可信。**

### 模式 4：诉求内部矛盾（宜阳离婚案）

原告："双方婚后购买房产价值40万元，原告**自愿放弃该房产所有权**，但被告应当将原告所有部分**折价给付**。"

两句不能并存。法院采信的是"归被告所有 + 支付折价"，实质读作"放弃房屋、主张一半份额"。

> **判据**：自相矛盾在诉状里**多半是诉求没写清，不必然是撒谎**。
> 但有区分度 —— **当事人自写的陈述里的矛盾，明显多于律师稿里的**
> （当事人没机会润色）。矛盾数量可作为"是否自述"的辅助判据。

### 模式 5：诉争对象漂移 —— 从事实转向法律效果（上海遗嘱案）

遗嘱笔迹四方无争议。争的是"缺日期算不算有效遗嘱"。

张某1的论证策略值得单独学：
- 承认形式瑕疵（"稍有瑕疵"、"未写明落款日期属轻微瑕疵"）
- 主张瑕疵不影响效力
- **引入价值论证**（"自认对上诉人有亏欠"、"亦不符合社会主义核心价值观所倡导的价值取向"）

> **判据**：**当事人在事实层面不占优时引入价值主张 = 目的层的直接证据。**
> 叙事分析在这里完全失效，必须换用法律框架（形式要件 vs 生效要件）。

**另有一个反向对照极有价值**：蒋某（被继承人母亲）主动为缺失的日期提供解释 ——
"基于张某4没有想到自己会这么突然离世，所以没有写上。"
→ **同样是"缺少日期"，雷某某隐瞒、蒋某坦白。同样客观事实缺失，两种处理方式，可信度完全不同。**
→ **判据：缺失项是当场主动补上，还是被对方指出后才出现。**

## B2. 家事案件的核心范式："说不清去向"即可推定

法院在雷某某案和汤阴案的表述高度一致，都**没有说当事人在撒谎**：

- 雷某某案："对其主张亦未提供证据证明，**对钱款的去向不能作出合理的解释和说明**"
- 汤阴案："**原告对提前支取未到期存单不能作出合理解释**"

> **不需要证明你说谎，只需要证明你说不出钱去哪了。**
>
> 这是法律场景最省力的判据，也是整套方法论在法律领域的核心落点。
> 对应到一般场景：**"无法解释"比"证伪"容易得多，且举证责任在主张方。**

## B3. 家事案件的特殊取证方向

| 方向 | 具体做法 | 针对模式 |
|---|---|---|
| **银行流水完整性** | 不接受当事人单方打印的切片，调开户至今全量 | 版本漂移（262.37元切片） |
| **销户/取现时间** | 查存单销户日、ATM交易时间，与起诉日比对 | 时间邻接 |
| **存款去向链路** | 资金转给谁 → 该人是否为亲属 → 是否有对应真实债务 | 说不清去向 |
| **证据持有与披露** | 谁领的公证、谁保管的原件、是否只提交一半 | 选择性提交 |
| **死亡前后资金流** | 老人去世当日/近日账户变动、取现次数 | 遗嘱真实意思表示 |
| **关系与权属披露** | 主张人是否抹掉共有权人、是否为近亲属 | 海淀案、杨某某案同源 |
| **对方视角复述** | 让对方复述同一件事，看是否补丁式补出 | 版本稳定性 |
| **旧版本比对** | 前后几次诉讼/调解中的陈述差异 | 全部 |

## B4. 婚姻案件特有的信号

1. **背景铺垫几乎总有功能。** 宜阳案里"原告常年在外打工，收入不稳定"看似自述不利，
   实为抚养权抗辩（我没收入 → 对方更适合带孩子 → 但我主张次女归被告）。
   → **不要把自述不利的话当中立信息跳过，要问它服务哪个诉求。**

2. **法条要件被前置对齐。** 宜阳案主动引用"经判决不准离婚后，双方又分居满一年"，
   且把 2021年8月判决、2022年11月起诉的时间点算得很准。
   → **当事人自写陈述的典型特征：把法律要件的构成事实前置并对齐。**

3. **情绪化细节会被过滤，不是被否定。** 孙丰杰案陈述"经常吵架，甚至相互动手"，
   法院查明版本直接换成"性格差异较大，在共同生活中产生矛盾"。
   → **差异存在不等于事实冲突，要先排除文体改写造成的差异。**

4. **自曝不利事实有两种用法**：孙丰杰主动说"两次起诉又撤诉"（真心，且补了理由）；
   张女士隐瞒另一份公证书（策略性沉默）。
   → **判据不是"有没有不利信息"，是"不利信息出现时是否配了解释"。**

5. **诉求与认定的差距是常态。** 宜阳案原告主张分割被告存款6万元，法院只认定35997.10元。
   → **法院对原告的诉求也是"能支持多少支持多少"。**

## B5. 十二案交叉印证：语言层指标的失效边界

把两轮共 12 份陈述（6 份一般民事/商事 + 6 份婚姻遗产）一起跑：

- **碎屑密度全部为 0**（12/12）
- **句长变异系数全部 < 0.6**

其中 **M2 孙丰杰是当事人自写**，碎屑同样是 0 —— 但时间锚点 6 处、精确数字 13 处、
句长变异 0.46，与律师改写的 M1（变异 0.16、时间锚点 3）明显不同。

> **修正后的结论**：
> - 碎屑密度 = **起诉状体裁**的共同特征，不是"律师改写"的特征
> - 区分"自写 vs 他人加工"的有效指标 = **时间锚点密度 + 精确数字密度**
> - 在法律场景真正生效的判据 = **版本稳定性、选择性提交、时间邻接、
>   关系/权属披露、诉求构造偏移、说不清去向**
>
> 详细数据见 `case-comparison-family.md` 末尾的交叉印证章节。
