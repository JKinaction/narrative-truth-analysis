## 一、这批材料为什么珍贵

前面 12 份裁判文书的最大局限：**全是书面整理过的**。而直播连麦是**未经律师改写的原始口述**。

这补上了三个此前无法检验的维度：

1. **口述的碎屑到底存不存在** —— 结论：不存在。口述同样被"要答案"的诉求压平。
2. **目的层在口述中是否更裸露** —— 结论：**是，而且裸露到几乎不加掩饰**。
3. **"第三方指称"（"我有一个朋友"）这个信号** —— 书面文书里见不到，只有口述里会出现。

## 二、连麦原话样本（逐字）

### L1 退彩礼（男，抖音切片）

> "我老婆羊水栓塞没了，留了个没用的女儿，我还得再娶啊，可以找她爸妈退彩礼吗？"

律师回应："你还可以要精神损失费呢。"
当事人回应："好啊。"

**拆解**：
- **"留了个没用的女儿"** —— 婴儿被指为"没用的"。这是价值判断前置，不是事实主张。
- **"我还得再娶啊"** —— 把妻子死亡与自己的再婚需求并列，**陈述里没有任何一句关于妻子或孩子的情感**。
- **诉求本身是纯粹的利益回收**：人没了，彩礼要回来。
- 全文 33 字，零碎屑、零时间锚点、零情绪词。
- 律师一句调侃（"要精神损失费"）被当事人**当成真实建议接住**（"好啊"）——
  → **当事人对法律风险的判断能力存疑，这是比陈述真伪更值得警惕的信号。**

### L4 拖时间等遗产（男，私信）

> "老婆她爸癌症晚期，到时候可以分到这部分遗产吗？"

**拆解**：全句 21 字，无任何情感词、无任何关于病人处境的描述。
- **唯一的时态是将来时**（"到时候可以分到"）—— 他要的是**未来时点的收益**。
- 短文本模式输出：财产词 3 处、权益型诉求 0 处 → **纯利益型，无伤害叙事**。
- 按原始框架，这属于"目的层露骨"的典型：叙述的对象不是人，是遗产份额。

### L13 婚前财产防火墙（男，老韩直播间）

> "我怕女方图谋我的两套房子，怎么办。婚前把两套房都全款，没有贷款就可以吗？或者婚前把房子全款还掉，婚后抵押做按揭，再慢慢还贷款这种形式可以吗？"

**拆解**：
- **"我怕女方图谋"** —— 直接给对手定了性（"图谋"）。
- 方案设计极其具体：婚前还清贷款 → 婚后抵押做经营贷 → 把婚后按揭变成"夫妻共同债务"。
- 短文本模式：**财产词 7 处、权益型 0 处、算计性 0 处、将来/可能标记 4 处、已发生事实标记 0 处**。
  → **"已发生事实标记 0"是极强的信号：整段陈述没有一个已经发生的事实，全是待执行方案。**
  → 这类咨询不是"发生了什么"，是"怎么设计"。**真实性判断在此完全不适用，适用的是正当性判断。**

### L15 假欠条换彩礼（男，老韩直播间）

> "老婆发现我pc闹离婚，我想要回彩礼，能不能跟我父母写个28万的欠条，作为夫妻共同债务，让女方还我14万。"

**拆解**：
- **"我想要回彩礼"** —— 事实层：妻子发现其嫖娼。
- **方案**：与父母虚构 28 万欠条 → 制造"夫妻共同债务" → 让妻子承担 14 万。
  → 净效果：用虚构债务把彩礼要走。
- 数字层：28 万、14 万，**精确到万位且成对出现** → 是在既有金额上做比例运算，不是在回忆具体金额。
- **这条与前面 M3 雷某某案、兰坪案形成跨域同构**：都是"通过虚构或伪造书证把财产转移出去"。

### L22 / L15 的梦幻联动（网友扒出）

- 6 月底，女方在龙飞律师处咨询：丈夫嫖娼，她要离婚，但男方要彩礼，问是否要还。
- 7 月初，男方在老韩处咨询：女方给父母打了 28 万欠条，自己被起诉承担一半债务，可不可行。
- 网友推出的完整故事线：**丈夫嫖娼被妻子发现 → 妻子提离婚 → 丈夫想通过假欠条制造共同债务来把彩礼要回来。**

> **这是本组最有价值的样本**：两个当事人、两个直播间、两个月、同一个金额（28万/14万），
> 而**没有任何一方说了完整的故事**。完整版本是**第三方（网友）交叉比对拼出来的**。
>
> → 这正是"稳定基线检验"和"交叉验证"的现实形态：**真相不在任何一个人的嘴里，在多个不完整版本的交集处。**

### L11 / L12 轻伤案（男，22岁，老韩直播间）

> "我打了别人一拳，肋骨骨折还有上颚骨裂，应该是属于轻伤的，但是TA先打的我，扇了我一巴掌。"

> "她之前也打过我。她之前一直在骂我。我本来就是为了她，从大城市跑回来，在小城市找了一个一份教师的工作。我只打了一拳。"

**拆解**：
- **主体延后披露**：先说"我打了别人"，说完一长段才透露"这个人是我女朋友"。
  → 书面陈述里做不到这个，书面有"当事人"栏。这种延后是口述特有的**渐进披露**。
- **短文本模式**：L11 自身不利披露 1 处；L12 责任前置 2 处（"她先""之前也""我为了她"）。
- **"我为了她"** —— 把职业选择包装成牺牲，是**归因策略**，不是事实。
- 律师的回应最见功力：
  > "她有没有打你，不妨碍你负刑事责任。" "她打你那一巴掌，连轻微伤害可能都算不上。"
  > **直接切断了责任前置的逻辑链**，比任何"你是否说谎"的质疑都有效。

### L8 仙人跳（男，老韩直播间）

> "我一个表哥被13岁女孩诱奸，现在不知道如何处理。"

> "我怀疑是女孩一家人'仙人跳'，她都不是'第一次'。" "他们有诈骗的嫌疑。"

**拆解**：
- 短文本模式：**第三方指称 1 处**（"我一个表哥"）+ 信息不对称标记 1 处。
- 凤凰网总结得最准：
  > "在这个直播间，只要说'我有个表哥''我有一个朋友''我有一个同事'。不用怀疑，就是他自己。"
- **"她都不是'第一次'"** —— 在没有任何证据的情况下，反向指控受害者。
- **"他们有诈骗的嫌疑"** —— 用刑事指控为自己脱罪，逻辑上是"如果我没罪，那她们就是有罪"。

### L6 好赌亲戚（男，老韩直播间）

> "我有一个亲戚人挺好的，就是好赌，欠的钱能不能算成夫妻债务。"

**拆解**：28 字，第三方指称 1 处，财产词 3 处，权益型 0 处。
- **"人挺好的，就是好赌"** —— 先给一个正面标签，降低后面诉求的冒犯感。这是一种**软化铺垫**。
- 诉求本质：把别人的债转成夫妻共同财产。

### L5 婚前算计（男）

> "在保持房子是我单独所有的情况下让女方陪我还房贷。"

**拆解**：21 字。**"在保持……的情况下"** —— 这是**目的陈述直接前置**，连遮掩都省了。
- 出现在她姐原文里的这一段，配的标题是"婚前就提前算计"。

### L14 要回猫（男）

> "谈恋爱送女朋友一只猫，分手后能不能要回来？"

**拆解**：这条和前面所有条目的**伦理量级完全不同**。
- 零碎屑、零情绪词、纯利益诉求——但**标的物是一只猫**。
- → **指标无法区分"算计"与"抠门"。** 同一个语言形态，动机量级天差地别。
- **这暴露了方法论的边界：语言指标测的是"结构"，不是"性质"。量级判断必须靠常识补。**

### L18 全职妈妈（女，极目新闻《律师来了》）

> "我是全职妈妈，老公每个月给3000元生活费，最近在沟通离婚，但我完全不清楚老公有多少财产，也不知道他工资有多少，我该怎么查？"

**拆解**：
- 短文本模式：**信息不对称标记 1 处** → 核心诉求是"我不知道对方有什么"。
- 第一人称 3、第二人称 3，**双线陈述**。
- 她的问题不是"怎么多分钱"，是"我连有什么都不知道"——**信息处于劣势的一方**。
- 对照 L13（男方也在防转移）：**同样的信息不对称诉求，方向完全相反**。
  → 所以"财产词密度"这类指标**必须配合方向词**才有意义。修正后的脚本已加防御性/算计性区分。

### L19 高净值妻子（女，极目新闻）

> "我和老公最近在闹离婚，我们名下资产比较多，除了房产、存款以外，还有几家公司，我生完二胎后就不怎么参与公司经营了，公司的经营状况我都不太了解，可能他还有其他的财产，请问我该怎样预防？"

**拆解**：
- 已发生事实标记 4 处（事实咨询，有核实抓手），防御性表述 1 处。
- **修正后的脚本正确判为"防御型，非算计"**。
- **"我生完二胎后就不怎么参与公司经营了"** —— 这句表面是自述，实则是一份**已经完成的事实陈述**：
  她长期退出经营 → 对公司资产没有信息权和控制权。
  → 这是**弱势方陈述中最有力的一类证据**：不是控诉，是陈述客观状态。

### L20 婆婆的借条（女，极目新闻）

> "我公婆给200万元买房，房子写了我和老公的名字。现在离婚，结果我婆婆拿出一张200万元的借条，写的是老公向他父母借款200万元，这张借条只有老公自己的签名。如果这种情况下，起诉到法院，法院一般会怎么判呢？"

**拆解**：
- 这条是**最接近裁判文书语体**的口述（结构完整、有具体金额、指向明确）。
- 双线陈述：第一人称 3、第二人称 4。
- **她准确抓住了最有价值的那个细节**："这张借条只有老公自己的签名。"
  → 只有一方签字 + 签字方是父母 → 推定赠与（律师的解答正是如此）。
- → **女性陈述的信息密度与法律要点抓取能力，明显高于男性样本。** 这一点在下面量化。

## 三、量化对照：口述 vs 书面

### 3.1 短文本模式输出（新增功能）

原脚本基于密度和方差，在一两句的口述上全部归零。为此新增 `--short` 模式，
改用**不依赖文本长度**的结构特征指标：

| 指标 | 含义 | 指向 |
|---|---|---|
| 第三方指称 | "我有一个朋友/表哥/亲戚/同事" | 不愿承担陈述主体身份 |
| 自身不利披露 | "我打""我先打""我错了" | 可信度信号 |
| 责任前置 | "她先""之前也""我为了她" | 为自身行为找减责叙事 |
| 财产/债务词 | 彩礼、房子、欠条、债务… | 利益导向 |
| 权益型诉求词 | 抚养、家暴、出轨、净身出户… | 受害叙事 |
| 信息不对称 | "不知道""完全不清楚""怎么查" | 信息获取型诉求 |
| 防御性 / 算计性 | "预防""防他" vs "图谋""钻空子""要回来" | **利益诉求的方向** |
| 已发生事实标记 | "了""当时""去年"… | 事实咨询（有核实抓手） |
| 将来/可能标记 | "能不能""可不可以""怎么办" | 方案咨询 |

### 3.2 实测结果

| 样本 | 第三方指称 | 责任前置 | 财产词 | 权益词 | 信息缺口 | 防御 | 算计 | 事实标记 | 将来标记 |
|---|---|---|---|---|---|---|---|---|---|
| L1 退彩礼 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 2 | 0 |
| L4 等遗产 | 0 | 0 | **3** | 0 | 0 | 0 | 0 | 0 | 1 |
| L5 婚前算计 | 0 | 0 | 4 | 0 | 0 | 0 | 0 | 0 | 1 |
| L6 好赌亲戚 | **1** | 0 | **3** | 0 | 0 | 0 | 0 | 0 | 1 |
| L8 仙人跳 | **1** | 0 | 0 | 0 | 1 | 0 | 0 | 0 | 0 |
| L11 轻伤 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 2 | 0 |
| L12 轻伤续 | 0 | **2** | 0 | 0 | 0 | 0 | 0 | 7 | 0 |
| L13 两套房 | 0 | 0 | **7** | 0 | 0 | 0 | 0 | **0** | **4** |
| L15 假欠条 | 0 | 0 | 3 | 0 | 0 | 0 | 0 | 0 | 1 |
| L18 全职妈妈 | 0 | 0 | 0 | 0 | **1** | 0 | 0 | 1 | 1 |
| L19 高净值 | 0 | 0 | 3 | 0 | 0 | **1** | 0 | 4 | 1 |
| L20 借条 | 0 | 0 | 3 | 0 | 0 | 0 | 0 | 1 | 1 |

### 3.3 三条从数据里长出来的结论

**结论一：短文本上，原指标 100% 失效，必须换指标集。**
L1（33字）到 L13（60字），密度类指标全部归零、方差无意义。
→ **任何依赖"文本量"的指标都有最低门槛。低于门槛时，唯一的正确做法是换判据，不是硬读数字。**

**结论二：L13 的"已发生事实标记 0"是最容易读、也最有用的一个指标。**
"我怕女方图谋我的两套房子，怎么办。婚前把两套房都全款…婚后抵押做按揭…"
—— 全是待执行方案，没有一个已发生事实。
→ **"事实咨询"和"方案咨询"必须分开处理。**
方案咨询里，问"这件事能不能成"本身就是答案，不需要再问真伪。

**结论三：方向词（防御/算计）不可省。**
L19（高净值妻子防转移）和 L13（男方设计让女方还贷），
**财产词密度、疑问结构、整体形态高度相似**，但性质完全相反。
只有加上方向词才能分开。修正后的脚本已实现。

## 四、男女样本的系统性差异

这是这批材料最值得注意的现象，媒体也反复提到（"一个是听别人说奇葩男人，一个是奇葩男人说"）。

| 维度 | 男性样本 | 女性样本 |
|---|---|---|
| 叙述重心 | 财产/债务/规避风险 | 权益/伤害/信息 |
| 情绪词 | **几乎为 0** | 偶有"委屈""净身出户" |
| 责任归因 | 大量前置到对方（"她先""之前也"） | 指向对方的伤害（"家暴""出轨"） |
| 事实颗粒度 | 模糊（"亲戚""朋友""表哥"） | 精确（金额、签名、日期、名字） |
| 追问方式 | 问"能不能""可不可以" | 问"怎么查""怎么判" |
| 典型诉求 | 让对方承担债务 / 拿回彩礼 | 查清财产 / 保住抚养权 |

**L20 与 L11 的对照最清楚**：
- L20（女）抓住"借条只有老公自己的签名"——**这是决定判决的关键细节**，律师的回答正是从这点出发。
- L11（男）说"我本来就是为了她，从大城市跑回来…我只打了一拳"——**这是为暴力行为找的减责理由**，与案件定性无关。

> **同一个人身上，"具体"和"空泛"不是性格问题，是立场问题。**
> 当事人的叙述精度，取决于这件事对他有利还是不利。

### 交叉印证：这与前 12 份裁判文书一致

前面 M3（雷某某）"始称家庭开销，后称偿还外债"——**版本漂移**；
前面兰坪案"因购车借款"但钱在购车半年后到——**时序倒置**；
前面 M4 海淀案——**选择性提交**。

**直播口述里的算计型陈述，用的正是同一套手法**：
虚构书证（L15）、设计时序（兰坪式）、把责任前置（L12）。

→ **手法跨场景通用。识别它们的判据也通用：版本稳定性、时间关系、选择性提交、关系披露。**

## 五、这批材料给方法论的三处修正

### 修正 1：碎屑不是"文书化"的产物，也不是"真实"的标志

前一轮结论是"碎屑密度为 0 是起诉状体裁的产物"。现在有了口述样本，结论要再推一步：

**口述样本的碎屑密度同样是 0。** L1 只有 33 字，L4 只有 21 字。

→ 修正：**碎屑密度低的原因是"诉求导向的短陈述"**，
而不是"书面化"。凡是把陈述压缩到"事实 + 诉求"结构的场景，碎屑都会消失。

→ **碎屑只在"不服务于任何诉求的闲聊式叙述"里出现** —— 比如她姐那篇里"妈饺八毛"、
"你那杯13"这类闲笔。它本来就不该出现在法律咨询里。

**这条修正让 signal-catalog 里"真实回忆有碎屑"这条判据的适用范围明确了下来：
它适用于"目的不强的叙述"（日记、闲聊、口语转述），不适用于"有明确诉求的陈述"。**

### 修正 2：短文本场景需要一套独立指标，且必须带方向

已在脚本中实现 `--short` 模式。最核心的三条：
- **第三方指称**（"我有一个朋友"）—— 只有口述会有
- **事实标记 vs 将来标记**—— 区分事实咨询与方案咨询
- **防御性 vs 算计性**—— 区分利益诉求的方向

### 修正 3：目的层在口述中的信号强度，远高于书面

前面 12 份裁判文书里，动机要靠"当事人陈述 vs 法院查明"的差异反推。
**口述里，动机直接写在脸上**：

- "留了个没用的女儿"（L1）
- "我还得再娶啊"（L1）
- "老婆她爸癌症晚期，到时候可以分到这部分遗产吗"（L4）
- "我怕女方图谋我的两套房子"（L13）
- "在保持房子是我单独所有的情况下让女方陪我还房贷"（L5）
- "我怀疑是女孩一家人'仙人跳'"（L8）

→ **书面文书会磨掉动机，口述不会。**
→ 这是法律场景里**目的层分析最好的取样层**，可惜只有直播能提供。

## 六、直播这个场景的独特价值

前面 12 份文书，我只能做"陈述 vs 法院查明"的单向对照（因为法院给出了真值）。
**直播场景没有法院，所以必须靠方法本身。** 这反而验证了框架的可用性：

| 场景 | 真值来源 | 主要手段 |
|---|---|---|
| 裁判文书 | 法院查明、鉴定意见 | 对照 + 外部核验 |
| **直播连麦** | **无** | **方法本身：目的层 + 结构信号 + 交叉比对** |

具体到实操，直播场景里最有效的三招：

**第一招：先分事实咨询还是方案咨询。**
L13 问"婚前全款可不可以"——这是在问可行性，不是在问真伪。**先分清要什么，再谈方法。**

**第二招：拆双线陈述，看两边详细度是否对称。**
L20 精确到"借条只有老公自己的签名"，L13 说"两套房"却不说哪两套、什么时候买的。
→ **不对称本身就是信号。**

**第三招：找跨样本的交叉点。**
L15（男方假欠条）和龙飞直播间的女方咨询，28 万/14 万这个数字对得上，
**完整故事线是拼出来的，不在任何一个人的嘴里**。

→ 这就是"稳定基线检验"的最高形态：**当单个人的陈述必然不完整时，
真相在多个不完整版本的交集处。**

## 七、一个必须记录的伦理边界

这批材料里有真实当事人（"羊水栓塞""癌症晚期""13岁女孩"），且都是被直播公开传播的。

**分析时必须守住三条**：

1. **只分析陈述结构，不做事实认定。** 这些咨询没有裁判文书，孰真孰假无从判断。
   本文件的所有"拆解"都是关于**怎么说话**，不是关于**事实是什么**。
2. **不复制可识别信息。** 涉及未成年人、具体金额、具体伤情的部分，
   在引用时保持分析所需的最小限度。
3. **不做道德审判。** L14（要回猫）和 L1（退彩礼）在语言结构上几乎一样，
   但**量级天差地别**——这正说明**语言指标测不出性质，性质需要另行判断**。
