# 直播连麦实录（第二批）：新模式与指标压测

第一批见 `live-consultation.md`。本批新增 12 条样本，覆盖此前未触及的领域（劳动、继承、消费、借贷），
重点是**压测第一批判据**，并找出两种新模式。

样本存于 `assets/legal-cases/live/M*.txt`。

---

## 一、"两头占"模式（M1）—— 本批最高价值发现

> **当事人原话**："我不想接手房子，不想承担贷款，只想在这住着，怎么办？"
>
> **案情**：父亲去世，房子在继母名下，离婚协议约定归父亲，继母愿意配合过户。

**律师的回应（河南怀律律师事务所官方微博原文）**：

> "这个意见我们给不了。理由很简单——想继承房子的权利，就得承担房子的债务；不想还贷款，就别惦记房子。
> 又想占父亲的遗产，又不想承担贷款义务，这叫'**两头占**'。法律是为守规矩的人服务的，不是为钻空子的人服务的。"
>
> "免费连麦是真心帮人解决问题，但不是帮人占便宜。有些人觉得'免费咨询什么都该答'，
> 但我们有权利拒绝——拒绝的不是一个提问，而是一种投机取巧的态度。"

### 为什么这个模式值得单独记

前两批的所有偏移模式都发生在**事实层**（编造、隐藏、时序矛盾、版本漂移）。
这一条发生在**诉求层**——当事人说的每一句都是真的，但**要求本身自相矛盾**。

| 维度 | 已有模式 | 两头占 |
|---|---|---|
| 出错位置 | 事实描述 | 诉求结构 |
| 需要的核实 | 大量外部核验 | **一句话就能判断** |
| 当事人的处境 | 可能被骗 | 试图占便宜 |

### 识别判据（已实现为脚本指标 `free_rider_count`）

**要权利 + 明示不愿承担对应义务**，两者同时出现。

M1 实测命中 **3 处**："不想接手""不想承担""只想在这住"。
匹配词表：不想承担 / 不想还 / 不想接手 / 不用还 / 不承担 / 不想管 / 只想在这住 / 不用过户 / 不想办手续 / 不想负责 / 甩给我。

### 附带发现：律师的"拒答"也是一种回应

这段材料的价值不只在识别当事人，还在**展示了专业者的应对方式**：

- 不做道德评价（没说"你这是耍赖"）
- **给出法律规则**（继承权利与债务同时转移）
- **命名模式**（"这叫两头占"）—— 命名让当事人能记住、能复述
- **明确划边界**（"我们有权拒绝"）
- 附带解释**为什么免费咨询不等于什么都该答**（公益边界）

> 这与"老韩"处理轻伤案的方式同构：**直接切断对方的逻辑链，而不是质疑其诚信**。
> 老韩："她有没有打你，不妨碍你负刑事责任。" 赵律师："想继承房子的权利，就得承担房子的债务。"
>
> **两条都是"不回答'你是不是在骗人'，直接回答'你的诉求在法律上不成立'"。**
> 这是比真伪分析更实用的一层——真伪分析是为了决策，而这一层直接给出结论。

## 二、纯权益型诉求（M5）—— 补上一个判定漏洞

> **当事人原话**："我父母在我八岁离婚，法院把我判给我爸，但是我十八岁前一直住爷爷家，
> 父亲并未尽到一点责任，我可以断绝父子关系吗？"

### 暴露的脚本漏洞

第一版短文本模式的判定逻辑是：

```
if 财产词 >= 2 and 权益词 >= 2:  → "利益与伤害并存"
```

M5 的实际情况：**权益词命中 4 处**（未尽、责任、断绝、关系），**财产词 0 处**。
因为它不匹配"财产词≥2"的前提，**整个分支被跳过，零判据输出**。

→ **修复**：新增独立分支 `财产词 == 0 and 权益词 >= 2` → 判为"纯权益型诉求"。

### 为什么这个区分重要

诉求的三种性质在实务上导向完全不同的应对：

| 诉求性质 | 样本 | 核心问题 | 应对方 |
|---|---|---|---|
| **纯权益型** | M5 断绝父子关系 | 关系/责任/赡养 | 情感＋法律双重回应，律师答"非常同情你的遭遇，但是…" |
| **混合型** | M4 二婚房产 | 房子 + 孩子 | 需要分层处理 |
| **纯利益型** | L13 两套房 | 钱怎么分 | 直接算账 |

M5 的律师回答也印证了这个区分——先接住情绪（"非常同情你的遭遇"），
再讲规则（"血亲关系不能断绝"），最后提醒反向风险（"父亲年老之后的赡养义务，您也继续要履行，否则他也是可以起诉你的"）。

**注意最后那句**：律师不只回答"你不能"，还提示"你不做会有后果"。
这在直播场景尤其重要——对方可能只有这一次免费咨询机会。

## 三、黄金90秒法则：第一批判据的"制度性反例"

浙江合飞律师事务所那篇《法律咨询直播免费？最新处理流程 实操建议》，
表面是实用指南，实际**为第一批判据提供了反向验证**。

### 平台的连麦规范

> "律师单次连麦限90秒，务必开头直说：
> '我是XX市XX区，2024年6月离职，公司拒开离职证明，已申请劳动仲裁但被以"超期"驳回——请问补正程序怎么走？'
> （**不说背景故事，不问'我该怎么办'，聚焦一个可裁断的具体问题**）"

> "✘ 绝对禁止：上传他人隐私信息（如配偶身份证号）、**模糊表述（'他欠我很多钱'）**、
> **情绪化描述（'老板就是黑心'）——此类将被系统自动终止连麦**"

### 这解释了前面所有的现象

| 观察到的现象 | 制度性解释 |
|---|---|
| 短文本里**几乎没有情绪词** | 情绪化描述会被系统终止连麦 |
| 短文本里**全是财产词、极少感受词** | 模糊表述被劝退，要说清金额、日期、主体 |
| **碎屑密度为 0** | 背景故事被明确劝阻（"不说背景故事"） |
| 大量样本是**将来/可能句式** | 90 秒内必须快速给出可裁断的问题 |
| **追问式提问为主** | 平台要求"聚焦一个可裁断的具体问题" |

> **重大修正**：前面说"碎屑为 0 是因为诉求导向的短陈述"，
> 现在可以说得更准：**平台规则把这一特征制度化了**。
> 律师直播间主动筛选出"事实清晰 + 诉求明确 + 无情绪"的陈述形态。
>
> → 这意味着**直播连麦样本是经过平台规则筛选的**，
> 不是自然分布的陈述样本。用它做真伪分析时，要意识到这个筛选偏差。

### 三条被劝退的表述，正好对应第一批的三类信号

1. **"情绪化描述（老板就是黑心）"** → 对应情绪词指标
2. **"模糊表述（他欠我很多钱）"** → 对应精确数字密度指标
3. **"不说背景故事"** → 对应碎屑密度指标

**平台的劝退清单，本质上就是一份"什么样的陈述不受欢迎"的清单。**
反向读，它就是"什么样的陈述在此场景会被采信"。

### 另一个被忽略的风险

> "误区1：'主播说"能赢"我就放心起诉' → 实务中法院审查的是**证据链完整性，而非口头判断**，
> 某当事人依直播建议起诉索要精神损失费，因无伤残鉴定+无诊疗记录，一审即驳回。"

> "若律师在直播中作出明确结论（如'这肯定算工伤'）且当事人据此放弃时效内维权，
> 可能被认定存在注意义务瑕疵（参见(2023)京02民终11XXX号裁定）。"

> "近三年372份相关判例中，92.6%法院认可合规直播内容不构成'承诺性意思表示'"

→ **直播回复有证据地位，但很弱。** 这条对"用直播内容做真伪判断"是直接的警示：
**直播里律师说"你这样能赢"，不等于事实成立。**

## 四、领域扩展样本

### M8 劳动权益（郝律师·快手新知播）

> 求助者："公司不给我上五险一金怎么办？我该怎么维权？"
> 郝律师："你可以通过当地的社保电话、官网、支付宝、微信小程序等方式查询你的五险一金缴纳情况，
> 如果你和单位签订的是劳动合同，不是劳务合同，而公司又没有为你缴纳或足额缴纳五险一金，
> 你可以去当地的劳动人事和监察部门求助，也可以以此为理由解除劳动合同并提起劳动仲裁，让单位给你补偿。"

**拆解**：短文本模式命中 [时态]（将来句式）、[结构]（疑问密度 95/千字，全批最高）。
- 疑问密度 95 意味着：**整段是问句，没有一个陈述句**。这是"求助型咨询"的典型形态——
  当事人不要叙事，只要路径。
- 律师的回应结构值得学：**先给查询工具（自主）→ 再给法定条件（判断）→ 最后给程序选项（行动）**。
  回应的是"怎么办"，不是"谁对谁错"。

### M9 要回车（龙飞律师直播间）

> "跟女朋友没结成婚，我全款买的车，写的她的名字，还能要回来吗？"
> 龙飞："可以，这叫**以结婚为目的的赠与**，如果说没有结成婚，从法律上来说，这个赠与并没有达成。"

**拆解**：命中 [结构] 两条，其中一条是 **"几乎只讲对方，很少讲自己"**——
这句话里"我"出现1次，"她"出现3次。
→ **这是 M13（刘琬琳那条"全职妈妈"）的镜像：同一指标，方向相反。**
前者是"我要占回来"，后者是"我要知道"。
**指标本身中立，方向词才能定性。**

### M12 代购红酒违约（辽宁卫视《金牌律师团》）

> "朋友让我从国外回来时带红酒一瓶2900多，和他约定需给付代购费，后来带回三瓶酒，
> 他只给了酒钱没给代购费，我不想给他了又把钱转回，但他没有收还声称要报警，我该怎么办？"

**拆解**：命中 [目的] 财产词5、[结构] 双线陈述。
- **信息密度全批最高之一**：2900多、一瓶、三瓶、转回、没收 —— 数字和动作链条完整。
- 律师的回答是**反向定性**："**是您违约了**"——当事人以为是对方欠钱，结果是自己违约。
- 承接"我不想给他了又把钱转回"这个动作后，律师没有顺着情绪走，而是直接指出法律后果：
  "他可能会起诉您，要求继续履行合同。刑事上您不会构成犯罪。"

> **值得记的一点**：直播里最常见的有效回应，不是"你能不能赢"，
> 而是"**谁违约**"。这个问句能把大量纠缠快速归位。

### M4 二婚房产（辽宁卫视）

> "我和老公是二婚，婚后买房付了首付，老公原来有个22岁孩子，如果我们离婚，他孩子能分这个房子吗？"
> 律师："**不能**。子女对夫妻共同财产无权享有，除非父母赠予他们。"

**拆解**：命中 [目的] 财产词3+权益词2 → 混合型。
- 回答只有一句话，因为法律关系清楚。**能一句话答完的，不必分析。**

### M6 借条无还款日期（辽宁卫视）

> "五年前借出的六万块钱，当时打了欠条，欠条上没有写还款日期，但现在还没有还，怎么办？"
> 律师："只能起诉维权。您要固定证据，如打电话、聊天取证。
> 欠条没有写还款日的话，诉讼时效是20年；写了日期的欠条诉讼时效根据情况是两年或者三年。"

**拆解**：命中 [目的] 财产词4。
- **"五年前""六万块钱""当时打了欠条""没有写还款日期"** —— 时间锚点精确但**不是时间序列**，
  是分散的事实要素。
- 与前面 L13（"已发生事实标记 0"）对照：M6 事实标记满格，因为陈述已定型，只差程序。

### M7 独生女过户（辽宁卫视）

> "我是独生女，父母已去世，父亲名下有套房，我怎么把它过户到我名下，父亲还有兄弟姐妹，他们有继承的权利吗？"
> 律师：需要办理继承公证、房产继承手续…儿女属于第一顺位继承人，他兄弟姐妹属于第二顺位继承人。

**拆解**：命中 [时态]——"将来/可能句式"。因为她的诉求是**程序性**的（怎么过户），
事实部分（父母已去世、父亲有房、有兄弟姐妹）已经陈述完毕。
→ 与 L13 的区别：L13 是**事实尚未成型**（方案还没执行），M7 是**事实已定、程序未走**。
→ **两者都是"将来时"，但性质完全不同。** 这是当前指标的一个局限，需要靠"已发生事实是否已陈述完整"人工区分。

### M3 微商举报（辽宁卫视）

> "在微商那里买减肥药品，收款了不发货，我给他举报了，但微商要起诉我耽误他赚钱，我该怎么办？"
> 律师："**您是正确做法，可以起诉**，用法律武器维护自己合法权益。"

**拆解**：命中 [目的] 财产词2、[结构] 两条。
- 与 M12 对照极有意思：M12 是"我违约了"，M3 是"我做对了"。
  → **同一个律师，同一场直播，两种完全相反的结论**。
  → 说明**咨询结论的方向由事实决定，不由当事人期待决定**。
  → 这也解释了为什么"顺着当事人说"的直播会被骂：**顺着说没有信息量**。

## 六、这一批最值得带走的四句话

**一、"两头占"是最省时的识别点。** 前面所有模式都要外部核验，只有这一条
当事人一开口就自我暴露：想拿权利，但明示不愿承担对应义务。

**二、直播平台在制度性地筛选陈述形态。** 劝退情绪化、模糊表述、背景故事——
这解释了为什么所有口述样本都碎屑为零、情绪词近零。
**用直播样本做真伪分析时，要意识到这个筛选偏差。**

**三、律师的回应方式比当事人的陈述更值得学。**
老韩："她有没有打你，不妨碍你负刑事责任。"
赵律师："想继承房子的权利，就得承担房子的债务。"
金律师（辽宁卫视）："是您违约了。"
王律师（辽宁卫视）："不能。子女对夫妻共同财产无权享有。"
→ **共同点：不评判诚信，直接指出法律后果。**
→ 这比真伪分析更实用——真伪分析为决策服务，而这一层直接给结论。

**四、直播回复有证据地位，但很弱。** "92.6%法院认可合规直播内容不构成'承诺性意思表示'"，
但也有认定律师"注意义务瑕疵"的裁定。
→ **直播里律师说"你这样能赢"，不等于事实成立。**
