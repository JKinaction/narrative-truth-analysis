# 婚姻 · 遗产继承类案例对照（陈述 vs 法院查明）

## 【M1】宜阳法院 离婚纠纷（张某诉王某）—— 争夺抚养权与财产折价

当事人陈述（原告张某）：
"原、被告之间矛盾频发，感情逐渐破裂，原告于2019年6月离家至今，常年分居。2021年7月原告起诉离婚，
2021年8月法院判决不准离婚，但被告至今没有任何改变，双方已无和好可能。双方婚后购买房产价值40万元，
原告自愿放弃该房产所有权，但被告应当将原告所有部分折价给付。原告常年在外打工，收入不稳定，
主张次女归被告抚养，三女归原告抚养。"

对方陈述（被告王某）：
"答辩人不同意离婚。答辩人现在没有工作，无能力抚养孩子。房产目前不值40万元，只值20万元。"

法院认定：
"原、被告于婚后共同购买案涉房产，双方在庭审中就该房产现价值20万元达成一致。"
判决：房产归王某，王某支付张某 100000 元。

差异拆解：
1. **"自愿放弃该房产所有权，但被告应当将原告所有部分折价给付"—— 内部自相矛盾。**
   "放弃所有权"和"要求折价给付"不能并存。这是诉求构造时的逻辑失误，
   法院采信了"归被告所有 + 支付折价"，实质是把它读成了"放弃房屋、主张一半份额"。
   → **诉状里的自相矛盾不必然是撒谎，也可能只是诉求没写清楚**。但当事人自写时通常会自己圆。
2. **40万 vs 20万** —— 同一标的，两个数字。法院以"双方在庭审中达成一致"取20万。
   注意：不是法院查明是20万，而是**双方庭审协商后一致**。这类"当庭改口"是常见的和解结果，
   不是虚假陈述。
3. **"原告常年在外打工，收入不稳定"** —— 表面是自述不利，实际是抚养权抗辩：
   自己没收入 → 对方更适合带孩子 → 对方却主张次女归被告。
   这句同时服务两个目的（争次女 + 为放弃房产铺台阶）。
4. **"经法院判决不准离婚后，双方又分居满一年"** 是法定准予离婚条件。
   原告陈述里"2021年8月法院判决不准离婚，但被告至今没有任何改变"——
   **主动引用对自己有利的法条事实**，且时间点算得很准（2021年8月判决 → 2022年11月起诉，跨满一年）。
   → 这是当事人自写陈述的典型特征：**把法律要件的构成事实前置并对齐**。

真伪判定：真实，诉求表述有逻辑瑕疵。

## 【M2】孙丰杰诉王玉萍离婚（最高法婚姻家庭纠纷典型案例）—— 唯一当事人自写的长篇陈述

当事人陈述（孙丰杰自己写的起诉内容）：
"孙丰杰与王玉萍于1992年经人介绍相识，1993年8月15日登记结婚，1994年6月生育女儿孙宁男。
婚后由于双方性格不合，在共同生活中经常吵架，甚至相互动手。从2007年3月起双方分居至今。
2011年女儿高考前夕，双方签订了离婚协议书和离婚协议书补充条款，但因种种原因没有办理离婚登记。
之后王玉萍拖延办理离婚手续，无奈孙丰杰于2012年10月、2013年7月两次到法院诉讼要求离婚，
后因需要搜集证据而撤诉。现孙丰杰第三次起诉要求与王玉萍离婚。"

对方陈述（王玉萍）："双方感情没有完全破裂，不同意离婚。"

法院查明：
"孙丰杰与王玉萍经人介绍相识，于1993年8月15日登记结婚，**婚后感情很好**，1994年6月生育女儿孙宁男。
后因双方性格差异较大，在共同生活中产生矛盾，现因感情不和分居四年。"

判决理由：
"通过孙丰杰给王玉萍留便条、发短信的行为，可以看出孙丰杰与王玉萍日常已经很少当面接触，
结合双方曾协议离婚、孙宁男的证言，可以确定双方因感情不和分居已达四年之久。"

差异拆解：
1. **"经人介绍" vs "经人介绍" —— 一致。但"婚后感情很好"是法院补的，不在陈述里。**
   法院的查明版本是中性化重写，把"经常吵架，甚至相互动手"替换成"性格差异较大，产生矛盾"。
   → **法院查明与当事人陈述的差异，有一部分来自"文体改写"而非事实冲突**。
   这与律师诉状不同：这里改写的是情绪化表述，不是核心事实。
2. **"分居至今" vs "分居四年"**：
   起诉时说"从2007年3月起分居至今"（2014年起诉，即7年），
   法院查明"分居四年"（认定2011年5月29日达成离婚协议补充条款起算）。
   → 差异来自**起算点的重新定义**，法院选了对自己更有利的（有协议佐证的那个时点）。
   **注意：这不是当事人说错，是法院选了更稳妥的认定基础。**
3. **"甚至相互动手"** —— 这是陈述中唯一带情绪色彩的一句，法院没有采纳也未否定，
   直接用"性格差异较大"替代。**情绪化细节在诉讼中被过滤掉，是它的常见命运。**
4. **"因需要搜集证据而撤诉"** —— 当事人主动披露自己两次撤诉。
   这是**自曝不利事实**：两次起诉又撤诉，客观上削弱"决心已定"的说服力。
   但因为同时说明了理由（搜集证据），反而强化了"我一直在尝试解决"的人设。
   → **自曝不利事实有两种用法**：真心的（孙丰杰），和包装过的（后面海淀案的张女士是另一类）。
5. **"王玉萍拖延办理离婚手续"** —— 直接给对方行为定性，且用了一个动机词（拖延）。
   这不是事实主张，是**归因陈述**。法院的查明版本里完全没有"拖延"这个评价。

真伪判定：真实。判决理由反而补强了当事人（用便条、短信、女儿证言三重客观证据支撑分居事实）。

## 【M3】最高法指导案例66号 雷某某诉宋某某离婚 —— 本组最强样本：同一当事人的陈述版本漂移

关键陈述序列（同一笔19.5万元）：
- 一审庭审中雷某某提交自己账户（尾号4179）自2014年1月26日起的交易明细，
  显示至2014年12月21日该账户余额为 **262.37元**
- 二审法院调取完整银行流水（自2012年11月26日开户后）后发现：
  雷某某于 **2013年4月30日** 通过ATM转账及卡取方式，将账户内 **195 000元** 转至案外人雷某齐名下
- 雷某某的解释：**"始称该款用于家庭开销，后又称用于偿还其外甥女的借款"**
- 且"雷某某在庭审中曾同意各自名下存款归各自所有，其另行支付宋某某10万元存款，后雷某某反悔，不同意支付"

法院认定：
"雷某某始称该款用于家庭开销，后又称用于偿还外债，**前后陈述明显矛盾**，对其主张亦未提供证据证明，
对钱款的去向不能作出合理的解释和说明。"
"另，雷某某在庭审中曾同意各自名下存款归各自所有，其另行支付宋某某10万元存款，后雷某某反悔，
不同意支付。"

判决：19.5万元存款归雷某某所有，但雷某某须补偿宋某某12万元（少分）。

差异拆解：
1. **这是"稳定基线检验"的教科书案例。**
   同一个当事人、同一笔钱、面对同一问题，前后给了两个解释。
   关键不是两个解释哪个是真的，而是**存在两个解释**这件事本身就是最强的信号。
   → 这验证了 signal-catalog.md 里"叙述者对不同听众/不同时点的说法是否稳定"这条检验的价值：
   **它完全绕开了"哪个说法更可信"的争论，直接指向"当事人没有稳定的故事"。**
2. **举证责任分配的巧妙处**：法院没有说"你的说法是假的"，
   而是"对其主张亦未提供证据证明，对钱款的去向不能作出合理的解释和说明"。
   → **"无法解释去向"就足以推定转移**。这在法律场景是个重要范式：
   **不需要证明你说谎，只需要证明你说不出钱去哪了。**
3. **账户余额 262.37元 也是一个陈述**：雷某某主动提交的交易明细显示余额几乎为零。
   单看这一份，像是在证明"我没钱"。二审调出完整流水才发现是2013年转走了19.5万。
   → **自证清白的证据本身可能是精心选择的切片**。银行流水可以只打印一段。
   这是"证据选择性提交"的典型形态，和之前兰坪案的"只提交对己有利的凭证"同源。
4. **"转至案外人雷某齐名下"** —— 转给亲属而非陌生人，且当事人是其外甥女（对应"偿还外甥女的借款"）。
   → 钱的去向和亲属关系叠加，可以互相印证或互相掩盖。
5. **"曾同意各自名下存款归各自所有…后反悔"** —— 庭上达成的合意自己推翻。
   这是典型的"谈判让步后的撤回"，在离婚财产分割中极常见。
   **注意框架里的判据：撤回本身不证明陈述为假，但撤回的时机值得问。**

真伪判定：陈述为真（确实转了钱），但**对去向的解释不可信**。法院的表述精确："存在转移、隐藏夫妻共同财产的情节"，而不是"陈述虚假"。

## 【M4】海淀法院 隐匿遗嘱案 —— 遗产领域的"选择性提交" + 利益计算错位

原告张女士诉称：
"1997年，王先生针对涉案房屋签订了购买合同。王先生的前妻去世后，王先生取得涉案房屋所有权证。
2000年，原告与王先生结婚。2010年，王先生在公证处办理了公证遗嘱，遗嘱确认：在王先生去世后，
涉案房屋中属于王先生的部分留给张女士个人所有。2020年，王先生去世。现诉至法院，
要求判决涉案房屋由张女士继承。"

被告（五名子女）辩称：
"张女士提交了2010年公证遗嘱，但是**隐瞒了王先生放弃继承涉案房屋中属于原配份额部分的公证遗嘱**，
两份公证书是张女士前往公证处领取的，但却隐瞒王先生放弃继承原配部分的公证，
张女士的行为构成篡改、隐匿遗嘱。"

法院认定：
"案涉两份公证遗嘱**均为原告领取**，在向法院提交了涉案房屋由其继承的公证遗嘱原件的同时，
未提交王先生放弃继承遗嘱公证书；原告在起诉中未表明存在王先生放弃继承的公证遗嘱一事，
反而主张涉案房屋由其全部继承；综上，可以证明原告存在隐匿遗嘱的事实。"

判决：王先生部分50%中，原告继承45%，五子女各1%；
前妻部分50%因王先生放弃继承，五子女各1/5。合计原告45%，五子女各11%。

法官说法：
"如果张女士未隐匿部分公证遗嘱，则其可以分得50%的房屋份额，
但本案中张女士因隐匿部分公证遗嘱，最终法院判决其少分房屋份额即只分得45%的房屋份额。"

差异拆解：
1. **"要求判决涉案房屋由张女士继承" vs 实得45%** —— 诉求是全有，结局是近乎全无。
   关键在于：**两份公证书都是她领的，她交了一份、藏了一份。**
   → 这是"选择性提交"的教科书形态。**陈述不是编的，是漏的。**
   漏掉的比说出来的更致命。
2. **"王先生的前妻去世后，王先生取得涉案房屋所有权证"** —— 陈述把房屋说成是王先生"取得"的，
   隐去了前妻的份额。法院查明："涉案房屋系前妻去世前由王先生签订购买房屋协议书，
   并一次性付清购房款，系王先生与前妻的夫妻共同财产。"
   → **叙述所有权来源时抹掉共有权人**，和之前杨某某案"称对方为我的雇主"是同一类：
   **关系/权属披露缺失。**
3. **张女士的陈述里完全没有"王先生放弃继承前妻份额"这件事** ——
   不是说了假话，是这件事压根没出现。
   → **沉默的重量**：在"我要继承全部"这个框架下，放弃继承前妻份额对张女士明显不利，
   沉默本身就是策略。
4. **张女士有没有说谎？ 严格说没有。** 她说的每一句都是真的。
   但她**主张了"由我继承"，而这与她掌握的材料不一致**。
   → 这再次印证那个核心区分：**"陈述真实"和"陈述可信"是两件事**。
   她的陈述真实，但不完整，而法律关心的是完整性。

## 【M5】汤阴法院 转移存款案 —— "说不出去向"的举证责任范式

原告（刘某某）事实与理由：
"原、被告经人介绍后相识，原告带1岁2个月的儿子与被告相识1个月后于2012年6月18日登记结婚…
因仓促成亲，后因生活琐事吵架不断，2021年秋天原、被告曾一起到婚姻登记处进行离婚登记，后被告反悔。
原告认为与被告感情确已破裂，已无和好可能，为此提起本案诉讼。"

被告（单某某）辩称：
"三、原告在提起离婚时，**擅自将未到期的两笔存款134200元及利息1万多元共15万之多于2022年3月2日取出转移**，
系法律所规定的转移隐匿共同财产非法之举，根据民法典规定，原告不应得到此款，应全额退还被告。"

法院认定：
"该两张存单已分别于2022年3月1日、3月2日销户，原告提前支取未到期存单，利息实际未能支取，
实际原告支取金额应为134200元；对该134200元，**原告未向本院提供证据证明已实际支出用于夫妻共同生活、
共同经营或偿还共同债务**，也未向本院提供证据证明该134200元存款中有部分款项系原告婚前个人财产，
被告对原告所称的存款事实及去向不予认可，**原告对提前支取未到期存单不能作出合理解释**，
鉴于原告存在隐藏、转移夫妻共同财产行为，应当少分该部分财产，
本院酌定按原告40%、被告60%的比例对该134200元予以分割。"

法院认定的"转移"证据：
- 两张存单的**销户日期**（2022年3月1日、3月2日）—— 与原告起诉时间紧邻
- 存单**未到期**却提前支取，**利息实际未能支取**
- 原告**未能说明资金去向**

判决：原告反而需给付被告 61521.45元。庭后原告当场现金履行完毕。

差异拆解：
1. **时间是靠"程序节点邻近"推出来的，不靠当事人承认。**
   起诉时间是3月，销户是3月1日和3月2日。原告没有说自己在转移，
   是时间顺序自己暴露的。
   → **"行为发生在哪个时间点"比"当事人怎么解释那个时间点"更可信。**
2. **"提前支取未到期存单"是一个可以被证伪的具体动作。**
   法院没有问"你是不是转移了"，而是认定"利息实际未能支取"这个客观事实，
   再问"那提前支取的钱去哪了"。
   → **先抓客观行为，再问解释**，这是比直接质询更有效的顺序。
3. **原告抗辩句式值得注意："因仓促成亲"** ——
   这是"仓促结婚"的表述，即暗示自己是被动方、对方有责任。
   同时"原告带1岁2个月的儿子与被告相识1个月后…登记结婚"，
   也是在强调自己带着孩子、婚basis不牢。
   → **婚姻案件里的"背景铺垫"几乎总是在为某项具体诉求服务**，不能当作中性信息跳过。
4. **原告主张分割被告存款6万元，法院只认定保险36000 + 余额1997.10元。**
   原告自己的诉求（60000）与法院认定的（35997.10）也有差距 ——
   **法院对原告的诉求也是"能支持多少支持多少"，不是照单全收**。

真伪判定：法院认定存在转移、隐藏。这里的判定同样不是"她在撒谎"，
而是"她说不清钱去哪了"。

## 【M6】上海二中院 张某1遗嘱继承纠纷 —— 遗嘱形式争议与"只主张对自己有利的"

上诉人张某1（一审原告）上诉请求：
"撤销一审判决第一至五项，改判遗嘱有效，按照遗嘱内容处理遗产：
(1) 房屋一半产权由上诉人张某1继承；(2) 被继承人张某4名下所有A股证券、基金由上诉人张某1继承；
(3) 被上诉人王某名下B股证券(美元9,103.85元)的二分之一由上诉人张某1继承；
(4) 被继承人张某4名下银行卡内银行存款归上诉人张某1所有（其中被上诉人王某已取出10,347.91元，余额47.91元）"

上诉理由（节选）：
"一、遗嘱的形式上稍有瑕疵，不应影响立遗嘱人真实意思表示的生效…
'亲笔书写、签名，注明年、月、日'是《继承法》第十七条规定的自书遗嘱的形式要件，
**但并不是法律所规定的遗嘱的生效要件**。涉案遗嘱未写明落款日期属轻微瑕疵…
二、上诉人系被继承人与前妻所生唯一女儿，被继承人再婚后很少与上诉人在一起生活，
**自认对上诉人有亏欠**，被继承人遵从自己的内心感受，以自书遗嘱的形式将其名下的财产留给上诉人，
系其真实意思表示。若仅以存在轻微瑕疵为由否定该份自书遗嘱…**亦不符合社会主义核心价值观所倡导的价值取向**。"

被上诉人王某、张某2辩称：
"自书遗嘱由遗嘱人亲笔书写，签名并注明年、月、日是自书遗嘱得以生效的法定条件，缺一不可。
本案中，被继承人张某4的自书遗嘱没有注明日，缺乏遗嘱生效的法定必要条件，违反法律规定。"

一审法院认定：
"张某1提交了书面'遗嘱'，王某、张某2对该书面'遗嘱'是否出自被继承人张某4亲笔**没有提出质疑**。
但自书'遗嘱'能够发生法律效力的前提是必须符合法律规定的形式要件…
本案该份'遗嘱'**空缺了书写的具体日子**，不符合法定形式要件，故该自书遗嘱应认定为无效遗嘱。"

蒋某（被继承人母亲）辩称：
"被继承人将某放在单位保险柜里，其单位同事对此也是知道的…该遗嘱是被继承人张某4从头到尾书写的，
抬头有遗嘱两个字，后面有落款和年、月，只是没有写日，
**基于张某4没有想到自己会这么突然离世，所以没有写上**。"

差异拆解：
1. **最值得学的一处：遗嘱内容本身是自书、当事人对笔迹无争议。**
   争议不在真假，在**形式**。张某某四方都承认这份纸是老人写的。
   → **当事实无争议时，争议点会转移到"这个事实是否产生你想要的法律后果"。**
   这是叙事分析的一个盲区，必须靠法律框架补上。
2. **张某1的论证策略极其清晰，值得单独学**：
   - 承认形式瑕疵（"稍有瑕疵"、"未写明落款日期属轻微瑕疵"）
   - 主张瑕疵不影响效力
   - **引入价值论证**（"自认对上诉人有亏欠"、"符合社会主义核心价值观"）
   → 这是**目的层的直接证据**：她要的不只是"遗嘱有效"，还要"这个遗嘱应该被尊重"。
   价值论证的出现，通常意味着当事人知道自己在事实层面不占优，转而争取评价层面的支持。
   → **这是"目的层推断"的一个高价值语言信号：当事人在事实薄弱时引入价值主张。**
3. **蒋某的陈述里有一句罕见的心理证言**：
   "基于张某4没有想到自己会这么突然离世，所以没有写上。"
   → 这是在**为缺失的部分提供解释**，而不是掩饰。
   **和雷某某案对比极有意思**：同样是"缺少日期"，一个解释、隐瞒，一个解释、坦白。
   **同样的客观事实缺失，两种处理方式，可信度完全不同。**
   → **判据：缺失项是否当场被主动补上、还是被对方指出后才出现。**
4. **一审同时查明了一个对张某1不利的事实并写进了判决**：
   "被继承人去世当日其名下交通银行卡内原有余额10,347.91元，**当日取现4次，剩余47.91元**"
   → 老人去世当天，账户被取空。这个事实对"老人的真实意思表示"是致命的，
   因为它同时也可以被解读为"有人在老人去世后动了财产"。
   **法院把它查出来并写明**，而不是只处理遗嘱形式。
   → **真伪分析的启发：查"老人去世后"这个时间窗内的资金流动，比查遗嘱本身更能反映真实意愿。**
5. **张某1请求继承"王某名下B股证券二分之一"** —— 注意措辞。
   遗嘱里写的是"建菁名下的B股证券归双方共同所有"（即王某名下B股共有）。
   张某1把**遗嘱里一句关于共有关系的描述**，直接转成"我继承一半"。
   → **把"共有"偷换成"遗产"，是请求权构造层面的偏移**，与陈述层无关。
   一审的处理是"一半是张某4的遗产，由法定继承人继承"，没有直接支持。

真伪判定：遗嘱真实（笔迹无争议），但**主张的法律效果被扩张了**。
一审后四人按法定继承平分，二审维持。

## 婚姻遗产领域新增的五种偏移模式

1. **诉求内部矛盾**（M1）—— "自愿放弃所有权，但应折价给付"两句不能并存。
   → 婚姻案件里自相矛盾多半是诉求没写清，不是撒谎。但**自写陈述里的矛盾比律师稿里的多**，
   因为当事人没机会润色。可作为"是否当事人自述"的判据。

2. **版本漂移**（M3）—— 同一笔款，前后两个解释。
   → **本组最强信号**。不需要判断哪个是真的，"存在两个说法"本身就是结论。

3. **选择性提交 / 隐瞒同源证据**（M4）—— 两份公证书都是原告领的，交一份藏一份。
   → **陈述不是编的，是漏的。漏掉的比说出来的更致命。**
   判据：谁持有证据、谁有义务披露、是否只提交了对自己有利的部分。

4. **诉争对象漂移：从事实转向法律效果**（M6）—— 笔迹无争议，争的是"缺日期算不算有效"。
   → 叙事分析在此完全失效，**必须换用法律框架**。同时注意当事人引入价值论证
   （"符合社会主义核心价值观"）= 她知道事实层面不占优。

5. **"说不清去向"的推定**（M5）—— 法院不说"你在撒谎"，说"你不能作出合理解释"。
   → **不需要证明说谎，只需要证明说不出钱去哪了。** 这是法律场景的核心范式，
   也是整套方法论里最省力的判据。

## 交叉印证：语言层指标的失效边界再次被验证

把上一轮六份诉状 + 本轮六份婚姻遗产陈述一起跑：

- **碎屑密度全部为 0**（12/12）
- **句长变异系数全部 < 0.6**

其中 **M2 孙丰杰是当事人自写**，碎屑同样是 0 —— 但时间锚点 6 处、精确数字 13 处、
句长变异 0.46，明显区别于律师改写的 M1（变异 0.16、时间锚点 3）。

→ 结论修正：**碎屑密度不是文体产物，是诉讼文书体裁的共同特征**（起诉状本就是书面整理的）。
  真正能区分"自写 vs 律师改写"的指标是 **时间锚点密度 + 精确数字密度**，
  不是碎屑。

→ 由此，signal-catalog.md 中"真实回忆的碎屑"这一条在诉讼场景需要降权使用；
  真正在诉讼场景生效的是 **版本稳定性（M3）、选择性提交（M4）、时间邻接（M5）、
  关系/权属披露（M4）、诉求构造偏移（M1/M6）**。
