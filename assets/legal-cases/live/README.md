## 关键教学点

**14 条口述的碎屑密度全部为 0。**
→ 修正上一轮结论：碎屑为 0 的原因不是"书面化"，而是**"诉求导向的短陈述"**。
碎屑只在"不服务于诉求的闲聊式叙述"里出现。

**短文本上密度/方差类指标全部失效**（L1 仅 33 字）。
必须用 `--short` 模式：不依赖文本长度的结构特征指标。

**最重要的三条新指标**：
1. **第三方指称**（"我有一个朋友/表哥/亲戚"）—— 只有口述会有
2. **事实标记 vs 将来标记** —— 区分"事实咨询"与"方案咨询"（L13 事实标记 0）
3. **防御性 vs 算计性** —— 区分利益诉求的方向（L19 防御 / L13+L15 算计）

分析见 `references/legal/live-consultation.md`。

## 第二批的四个关键教学点

1. **"两头占"新模式**（M1）：要权利 + 明示不愿承担义务。
   诉求层自相矛盾，**一句话可识别，不需要外部核验**。
   → 脚本新增 `free_rider_count` 指标。

2. **纯权益型诉求**（M5）：财产词 0、权益词 4。
   诉求是关系/赡养，不是钱 —— 与利益型截然不同。
   → 脚本新增独立分支（此前因"财产词≥2"前提被整段跳过，零输出）。

3. **黄金90秒法则的筛选偏差**：平台明令劝退情绪化描述、模糊表述、背景故事。
   → **这解释了所有口述样本碎屑为零、情绪词近零的制度性原因**，
   也意味着直播样本不是自然分布的陈述样本。

4. **律师的回应方式比当事人陈述更值得学**：
   老韩"她有没有打你，不妨碍你负刑事责任"、
   赵律师"想继承房子的权利，就得承担房子的债务"、
   辽宁卫视"是您违约了"/"不能，子女对夫妻共同财产无权享有"。
   → 共同点：**不评判诚信，直接指出法律后果**。

分析见 `references/legal/live-consultation-2.md`。
