## 关键教学点

**12 份的碎屑密度全部为 0，句长变异系数全部 < 0.6。**
其中 `m6_sun.txt` 和 `m1` 是当事人**自己写的**，碎屑同样是 0。

→ **碎屑密度是"起诉状体裁"的共同特征，不是"律师改写"的特征。**
  区分"自写 vs 他人加工"的有效指标是 **时间锚点密度 + 精确数字密度**：
  `m6_sun`（时间锚点6、精确数字13、变异0.46） vs `m1`（时间锚点3、精确数字7、变异0.16）。

→ **法律场景真正生效的判据**（不是语言层）：
  版本稳定性（m4）、选择性提交（m3）、时间邻接（m5）、关系/权属披露（m3/c6）、
  诉求构造偏移（m1/m5）、说不清去向（m4/m5）。

对照分析见 `references/legal/case-comparison.md` 与 `case-comparison-family.md`。
