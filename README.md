# narrative-truth-analysis

> 判断一段事件描述的真伪——从语言细节、逻辑一致性、人性动机、叙述目的四个层面切入，
> 识别系统性偏移，重建可能的原貌，并为每个猜测给出可执行的验证方法。
>
> 也能拆"话里有话"——标注一句话在做什么动作、回避了什么、预设了什么，并给出可以怎么接。

一个 WorkBuddy Skill。把"读一段话看谁在说谎"从直觉变成可复核的流程。

---

## 它解决什么问题

面对一段事件描述（纠纷陈述、他人转述、投诉内容、聊天记录、裁判文书、直播连麦），
大多数人会在两个极端之间摇摆：

- **要么全信** —— 因为对方讲得连贯、细节丰富、有情绪。
- **要么全疑** —— 因为觉得对方动机不纯。

这两个反应都不对，因为**"描述真实"和"描述可信"是两件不同的事**。
一个陈述可以句句为真却完整地误导（隐瞒了不利于自己的那份证据），
也可以条条造假却抓住了关键细节。

本 skill 的核心主张是：**把事实层、叙述层、意图层拆开，分别判断。**

## 快速开始

### 安装

```bash
# 方式一：直接克隆到用户级 skill 目录
git clone https://github.com/JKinaction/narrative-truth-analysis.git \
  ~/.workbuddy/skills/narrative-truth-analysis

# 方式二：作为压缩包安装
curl -L -o nta.zip https://github.com/JKinaction/narrative-truth-analysis/archive/refs/heads/main.zip
unzip nta.zip -d ~/.workbuddy/skills/
```

### 使用

在 WorkBuddy 中说"分析这段描述的真假""这个说法可信吗""事件原貌是什么"即可自动触发。

也可以直接跑量化分析器：

```bash
# 书面材料（诉状、聊天记录长文、判决书陈述）—— 建议 ≥150 字
python3 scripts/analyze_narrative.py 描述.txt

# 口述材料（直播连麦、访谈、单条留言）—— 通常一两句
python3 scripts/analyze_narrative.py 描述.txt --short

# 拆"话里有话"（一句话即可）—— 言外动作、预设、回避、可接话术
python3 scripts/analyze_narrative.py "这个方案我们内部再讨论一下。" --implicature

# JSON 输出，便于批量处理
python3 scripts/analyze_narrative.py 描述.txt --json
```

## 五步分析流程

| 步 | 做什么 | 关键产出 |
|---|---|---|
| 0 | **定位五问** | 谁在说 → 对谁说 → 说了什么 → **没说** → **为什么现在说** |
| 1 | **分层拆解** | 事实主张 / 归因陈述 / 立场表达，分类归档 |
| 2 | **语言层扫描** | 按文本量选指标集（默认模式 / `--short`） |
| 2B | **语用层**（按需） | 四准则违反 / 言语行为 / 预设 / 语用标尺 / 回避映射 |
| 3 | **逻辑层检验** | 因果链强度、关键环节缺失、内部矛盾、可证伪性 |
| 4 | **人性层** | 识别系统性偏移（自利性偏差、归因错误、情绪回填…） |
| 5 | **目的层** | 推断 2–3 种可能目的，各配验证方向 |

之后是**竞争假设**（H1 如实 / H2 立场性偏移 / H3 蓄意构造 / H4 部分虚构）
与**区分性检验**——不是"找证据支持 H1"，而是"找一个 H1 和 H2 会给出不同结果的动作"。

---

## 两条贯穿全程的原则

### 一、目的 ≠ 可信度

带目的的叙述完全可能是真的。人都会带目的地讲真话。
**必须把"事实层真伪"和"意图层真伪"分开写。**

### 二、默认假设是 H2（骨架真、归因斜）

人极少为了具体的小事编造整套故事（成本高），但会系统性偏袒自己（成本近乎零）。
除非证据指向，不要默认"他在撒谎"。

## 新增能力：拆"话里有话"

不想查真假、只想知道"他到底什么意思"的时候，走这条：

```bash
python3 scripts/analyze_narrative.py "这个方案我们内部再讨论一下。" --implicature
```

输出长这样：

| 项 | 结果 |
|---|---|
| 言外动作 | 回避 / 拖延；责任转移 |
| 回避了什么 | 没有日期、没有参与人、没有下一步 |
| 预设了什么 | 无 |
| 承诺要素 | 日期 无 · 人名 无 · 数字 无（0/3） |
| 可以怎么接 | "好，那定个时间，下周几？谁参加？" |

底层是五套语用框架，不是靠感觉：

- **四准则违反**（Grice）—— 说少了 / 答非所问 / 故意含糊，违反哪条，言外之意就在哪
- **言语行为**—— 字面说的 / 实际动作（拒绝·试探·施压·免责·转移）/ 想让你产生的反应
- **预设提取**—— "你为什么还没交"预设了"你该交但没交"，摊开前提再判断整句
- **语用标尺**—— "还不错"是 60 分，"我们会研究一下"是 10 分，"我考虑考虑"是 3 分
- **回避映射**—— 我问的和答的并排列，中间缺的那块就是禁区

**输出纪律**：只写"看起来在拒绝"，不写"他在拒绝"。标注的是语言动作，不是动机。
每条判断都要能指回具体的形式依据。

详见 `references/implicature-playbook.md`。

## 指标：两套，按文本量选

**这是本 skill 与一般"读微表情"类方法最大的不同**——指标必须匹配文本形态，
否则会系统性误判。

### 书面材料（默认模式，≥150 字）

| 指标 | 含义 |
|---|---|
| 被动句比例 | 责任稀释程度 |
| 归因稀释标记密度 | "上面""流程""对接"类遮蔽 |
| 模糊限定词密度 | 关键处的确定性缺失 |
| 情绪词位置重心 | 情绪落在戏剧点还是受刺激点 |
| 细节碎屑密度 | 特异性强度 |
| 句长变异系数 | 参差（自然）还是整齐（编排） |
| 时间锚点数 | 时间线是否有洞 |
| 主张/支撑比 | 主张多支撑少 = 立场表达 |
| 强断言/支撑比值 | 空话型识别 |

### 口述材料（`--short`，一两句）

密度与方差类指标在短文本上**全部失效**（分母太小）。短文本模式改用
**不依赖文本长度**的结构特征：

| 指标 | 指向 |
|---|---|
| **第三方指称**（"我有一个朋友"） | 不愿承担陈述主体身份 |
| **责任前置**（"她先""之前也""我为了她"） | 为自身行为找减责叙事 |
| **自身不利披露**（"我打""我错了"） | 可信度信号 |
| **事实标记 vs 将来标记** | 区分事实咨询与方案咨询 |
| **财产词 / 权益词 / 信息不对称** | 诉求性质三分 |
| **防御性 vs 算计性方向词** | 利益诉求的方向（缺了会误判） |
| **两头占标记**（"不想承担""只想在这住"） | 要权利但明示不愿担义务 |

## 样本库：47 份真实材料，全部有真值标注

这是本 skill 与其他同类工具最大的区别——**样本全部来自可查证的公开来源**，
且多数带有"法院查明"作为真值基准。

| 来源类型 | 数量 | 价值 |
|---|---|---|
| 裁判文书当事人陈述 | 12 份 | 有"陈述 vs 法院查明"的天然对照 |
| 律师直播连麦原话 | 35 条 | 未经律师改写的原始口述 |

**已从 47 份样本中提炼出 20 余条偏移模式**，包括：

- 记忆合理化压缩、语感失真、时序倒置、精确度异常
- 版本漂移（同一笔钱两个解释）、选择性提交、时间邻接
- 关系/权属披露缺失、诉求构造偏移、诉争对象漂移
- **两头占**（要权利但不愿担义务）—— 一句话即可识别

以及三条**反复被验证的硬结论**：

1. **碎屑密度低的原因是"诉求导向的短陈述"，不是"书面化"。**
   26 份书面 + 口述样本实测，碎屑密度全部为 0。
2. **法律场景真正生效的判据不是语言层**，而是版本稳定性、选择性提交、
   时间邻接、关系披露、诉求构造偏移、"说不清去向"。
3. **法院不说"你在撒谎"，说"你不能作出合理解释"。**
   不需要证明说谎，只需要证明说不出钱去哪了。

## 测试

```bash
python3 tests/test_implicature.py
```

25 个用例，测三件事：

| 类别 | 数量 | 含义 |
|---|---|---|
| 真阳性 | 10 | 确实"话里有话"的句子，该不该检出 |
| **真阴性** | **10** | **完全字面表达的句子，会不会被过度解读** |
| 边界 | 5 | 空输入、单字、纯英文、超长——不崩溃即可 |

真阴性是最关键的一组。把一句正常的话拆成"话里有话"，比漏检更糟——
这套方法最大的风险不是不够敏锐，是**过度解读**。

当前状态：25/25。

## 伦理边界

本 skill 明确不做以下事情：

- **不做人格判断** —— 分析文本与偏移机制，不推断叙述者的道德品质或精神状态
- **结论是概率不是判决** —— 用"更可能 / 证据支持 / 尚无证据表明"表述
- **不代替证据** —— 产出的是假设与验证路径，事实认定需要外部证据
- **不做道德审判** —— 语言指标测的是结构不是性质，量级判断必须靠常识补
  （例："要回一只猫"与"退彩礼"语言结构几乎一样，量级天差地别）
- **敏感场景谨慎** —— 涉及纠纷、举报、诉讼材料时，输出定位为分析框架与核查建议

样本库中涉及真实当事人（含未成年人、伤情、金额）的部分，
引用时保持分析所需的最小限度，只分析陈述结构，不做事实认定。
